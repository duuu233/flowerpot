> 用途：为后续 AI 开发、页面拆分、路由设计、组件抽离与 Design Token 建设提供依据。
>
> 分析对象：Figma 文件 `智能花盆ysplanter`，Page `Page 1`。

## 1. 设计稿总览

- Figma Page：1 个，名称为 `Page 1`
- 顶层移动端画板：48 个
- 当前 `docs/UI` 导出图：49 张（后续补充了 `植物详情.png`）
- 实际独立页面/状态：约 47 个
- 重复稿：`首页-已添加植物` 存在 2 份近似画板
- 基准尺寸：375 × 812 px
- 原型跳转连线：未配置
- 本地组件：0
- 本地样式：0
- Figma Variables：0
- 本文跳转关系根据页面命名、入口文案与业务流程推导，开发前需进一步确认

## 3. 页面跳转关系

当前 Figma 未配置 Prototype Reactions，以下关系均为建议路由。

### 3.1 登录流程

- 验证码登录 ⇄ 密码登录
- 验证码登录/密码登录 → 注册页
- 密码登录 → 忘记密码
- 注册完成 → 登录页或登录后无设备
- 忘记密码完成 → 密码登录
- 登录成功：
  - 已绑定设备 → 首页-已添加植物或首页-未添加植物
  - 未绑定设备 → 登录后无设备
- 协议文字入口 → 用户协议/隐私政策

### 3.2 设备添加流程

主流程：

登录后无设备 → 搜索附近设备 → 选择设备 → 连接Wi-Fi → 连接设备成功或连接设备失败

分支关系：

- 连接Wi-Fi → 点击“切换” → Wi-Fi 选择弹层
- 配网失败 → 重新配网 → 连接Wi-Fi
- 配网失败 → 返回选择设备 → 选择设备
- 配网成功 → 添加植物 → 首页-已添加植物
- 配网成功 → 返回首页 → 首页-未添加植物
- 设备列表 → 选择设备 → 对应设备首页

### 3.3 首页与数据详情

- 首页头像 → 我的（推导关系，画板中无明确连线）
- 首页需水状态 → 水仓水位变化/土壤湿度变化
- 首页光照状态 → 光照状态
- 首页空气温度 → 空气温度
- 首页相对湿度 → 相对湿度
- 首页定制动画 → 定制动画
- 首页电池状态 → 电池状态
- 首页设置 → 设置
- 首页-未添加植物 → 添加植物 → 首页-已添加植物
- 数据详情页顶部返回 → 首页

水仓水位与土壤湿度两张画板建议实现为同一路由下的图表指标切换，而不是两个完全独立页面。

### 3.4 设置流程

- 设置 → 选择植物 → 选择植物 → 返回设置
- 设置 → 更多 → 更多设备信息
- 设置 → 显示
- 设置 → 听觉感知
- 设置 → 触觉感知
- 设置 → 震动设置
- 设置 → 行为
- 设置 → 其他设置

其他设置分支：

- 温度单位 → 温度单位选择弹层 → 确认/取消
- 时钟模式 → 时钟模式选择弹层 → 确认/取消
- 固件版本更新 → 更新弹层
- 水位传感器校准 → 第一步 → 第二步 → 第三步 → 第四步 → 其他设置
- 重新配网 → 连接Wi-Fi
- 恢复出厂设置、移除设备、修复系统文件 → 对应确认弹窗或结果状态，目前缺少设计稿

### 3.5 我的与账号流程

- 我的 → 个人信息
- 我的 → 账号与安全
- 我的 → 帮助中心
- 我的 → 隐私政策
- 我的 → 用户协议
- 我的 → 关于YSplanter
- 我的 → 意见反馈，目前缺少目标页面
- 个人信息 → 退出登录 → 登录页
- 账号与安全：
  - 未设置密码 → 登录密码
  - 已设置密码 → 修改密码
  - 忘记密码 → 忘记密码流程
- 关于YSplanter → 检查更新，目前未设计更新结果或应用商店跳转状态

## 6. Design Token

### 6.1 Token 现状

设计文件中没有建立正式的 Variables、Paint Styles 或 Text Styles。以下 Token 均根据实际图层高频值推导。

| Device Title | 20 / 500 | 设备名、校准步骤说明。 |
| Empty State Title | 24 / 500 | “还未添加植物”等强状态标题。 |

行高现状：

- 大部分文字使用 Auto Line Height
- 12px 指南文字存在约 185% 行高，即约 22.2px
- 12px 帮助文字存在约 158% 行高，即约 19px
- 14px 协议正文使用约 158% 行高，即约 22.1px
- 20px 校准说明使用约 147% 行高，即约 29.4px

行高尚未系统化，开发时不应仅按浏览器默认值还原。

### 6.4 间距

设计稿没有正式间距变量，但整体呈现明显的 4px 基础网格。

| 建议 Token | 数值 | 典型用途 |
|---|---:|---|
| Space XS | 4px | 紧密文字、图标内部间隔。 |
| Space 1 | 6px | 数值与单位、紧密控件间隔。 |
| Space 2 | 8px | 图标与文字、标签间隔。 |
| Space 3 | 10px | 小型内容块。 |
| Space 4 | 12px | 卡片间距、列表局部间距。 |
| Space 5 | 16px | 卡片内边距、内容组间距。 |
| Space 6 | 20px | 主页面左右边距、主卡片间距。 |
| Space 7 | 24px | 大区块分隔、弹窗内容间距。 |
| Space 8 | 32px | 页面主区块分隔。 |
| Space 10 | 40px | 大型空状态和插图区域。 |

关键布局尺寸：

- 页面宽度：375px
- 页面高度：812px
- 主内容左右边距：20px
- 主卡片常见宽度：335px
- 部分表单/按钮左右边距：28px
- 设置列表图标对齐线通常位于距左侧 38–42px
- 常见卡片间距：12px
- 常见卡片内边距：12–20px

### 6.5 圆角

| 建议 Token | 数值 | 当前用途 |
|---|---:|---|
| Radius XS | 4px | 小提示块、局部高亮。 |
| Radius SM | 6–8px | 小型控件、标签。 |
| Radius MD | 10px | 输入或局部状态容器。 |
| Radius Card | 12px | 最主要的卡片圆角，设计稿中使用频率最高。 |
| Radius LG | 14–16px | 较大卡片、选择卡片。 |
| Radius Dialog | 20px | 弹窗、大型面板。 |
| Radius Pill | 30px | 主按钮、搜索框、分段选中态。 |
| Radius Full | 100px/全圆角 | 胶囊标签、开关、圆形图标底板。 |

圆角值目前较分散，建议实现时收敛为 8、12、16、20 和 Full 五级；30px 与 100px 本质上均属于胶囊型圆角。

## 7. 开发前确认事项

- 明确两份“首页-已添加植物”画板中的最终版本。
- 补充或确认实际路由关系和返回逻辑。
- 确认设备列表、我的页面和首页之间的入口关系。
- 确认需水状态的两个图表是页面、Tab，还是图表指标切换。
- 补充意见反馈、植物详情和危险操作确认页。
- 补充固件升级进度、失败、完成状态。
- 将温度单位、时钟模式、Wi-Fi 切换、校准步骤实现为弹层状态，而不是独立主路由。
- 在开发前统一近似颜色、字号行高、圆角和间距，形成正式 Design Token。
- 建立共享组件，避免按 48 张画板逐页复制 UI。
