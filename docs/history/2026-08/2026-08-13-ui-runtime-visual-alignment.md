# UI 当前构建运行态对图与页面校准

> 文档类型：Historical Change Record
> 日期：2026-08-13
> 环境：办公室 Windows / Android 12 模拟器（375 × 812 逻辑视口）
> 分支与起始版本：`main` / `b0c773f`
> 范围：Flutter 首页、认证、设备、个人页、Design System 调用方、关联测试与 UI 文档
> 当前权威文档：`docs/UI/FLUTTER_UI_IMPLEMENTATION_STANDARD.md`、`docs/UI/UI_ASSET_INTEGRATION_PROGRESS.md`

## 背景与目标

继续 2026-08-12 的 UI 参考图复核。昨天已经接入普通页面正式背景与品牌资源，但尚未对修改后的新构建做模拟器截图验收。本次以 CodeGraph 确认共享组件和页面调用范围，再把当前源码构建安装到模拟器，与 `docs/UI` 的参考图逐页比对，修正有明确截图依据的位置、尺寸和局部密度偏差。

开始时源码基线为 `b0c773f`。工作树仅有 Android Kotlin 编译会话文件的既有删除状态；本次没有恢复或覆盖该本地生成文件。

## 变更内容

- 保留已经对齐的共享 `AppPageScaffold`、`AppPageHeader` 和 `ResponsiveContent`，只在设备列表/设置/信息/其他设置、五张状态详情、定制动画、帮助、注册和忘记密码页面调整各自内容起点。
- 首页三种场景统一下移顶栏，头像移到参考图左侧，正式字标缩放为参考尺寸；已添加植物场景增大并重新居中正式花盆主图。
- “我的”资料区上移；“关于 YSplanter”品牌区上移并调整正式字标尺寸；设备设置摘要花盆、功能区间距，设备列表卡片横向布局和其他设置两组卡片密度按运行态截图校准。
- 五张状态摘要卡统一增大花盆、收窄左侧槽位并重新分配上下留白，使右侧说明恢复参考图的两行布局；图表逻辑和其他功能性 `CustomPainter` 保持不变。
- 水位校准四步继续加载正式图片；图片失败分支改成带稳定 Key 的简单品牌色块和短文案，删除约 500 行复杂插画 Painter。设备列表空状态的 Material 设备图标替换为正式花盆资源。
- 更新过期的首页头像测试断言，以及首页、关于、水位校准 Active 文档；帮助答案只做局部字距修正，避免 Android 字体导致多余换行。

## 关键决策

- “显示”页使用 `top = 37` 时首卡与参考图精确重合，证明共享 Scaffold/Header 基线正确，因此没有通过共享层批量移动 34 个页面调用方。
- 只修改截图能够证实的局部字号、间距和图片尺寸，不全局修改 `AppTypography`；参考图的 iOS 状态栏和当前 Android 状态栏差异不作为页面内容偏差处理。
- 功能图表、扫描动画和登录结构绘制属于功能性绘制，继续保留。品牌标识、装饰插画和错误回退不使用复杂代码重绘。
- 模拟器演示仓库只有一个设备，而设备列表参考图展示三个设备；这是预览数据差异，不修改真实设备列表业务数据来伪造截图。

## 外部操作

- 通过 CodeGraph 检查共享 Scaffold/Header、页面内容组件、状态摘要卡和水位校准调用链；确认共享 Scaffold 有 34 个调用方。
- 在已连接的 Android 12 模拟器中依次打开并截图复核设备列表、设置、其他设置、显示、光照状态、首页、我的、关于、帮助、注册和定制动画等页面。
- 两次构建 `build/app/outputs/flutter-apk/app-debug.apk`，使用 Android build-tools 37 验证 v2 签名，并通过 ADB 覆盖安装到 `127.0.0.1:62001`。
- 对比截图只存放于本地临时目录，复核完成后已删除，未作为产品资源，也不参与跨环境交接。

## 验证结果

- `dart format`：本次 Dart 变更均已格式化。
- `dart analyze lib test`：通过，`No issues found!`。
- 第一次并发全量测试因 Windows 无法创建 DartWorker 线程中断；将并发降为 1 后发现并修正一条过期的“头像在右侧”断言。
- 相关页面定向测试：37 个用例全部通过，覆盖 375 × 812 与 320 × 568 可用性、设置交互和水位校准四步流程。
- 最终全量 `flutter test --no-pub --concurrency=1 --reporter compact`：180 个用例全部通过。
- `flutter build apk --debug --no-pub`：两次均成功；`apksigner verify --verbose` 确认 v2 签名有效；ADB 两次覆盖安装均返回 `Success`。
- 修改后 375 × 812 截图复核：普通背景覆盖与裁切正常；设备设置、其他设置、首页、我的、关于和光照摘要区的主要坐标、比例与内容流已对齐参考图。Android/iOS 系统栏、演示数据值和运行时头像属于预期差异。
- `codegraph sync .` 与 `codegraph status .`：通过，索引为最新。

## 未完成项与风险

1. 仍缺添加/选择植物列表的 6 张独立照片和植物详情主图；在正式素材补齐前继续保留语义色块，禁止从 UI 截图裁切。
2. 49 张参考图的资源接入已完成，但本次运行态重点复核不等于所有页面已经逐像素完结；后续继续检查配网链、协议正文和剩余弹层的局部字体与坐标。
3. 320 × 568 已由 Widget 测试覆盖无溢出和滚动可用性；尚未在实体模拟器上逐页保存该视口截图。
4. 设备列表当前模拟器只有一条演示设备，未通过修改业务数据来模拟参考图的三条设备；需要专用多设备预览场景时应单独设计，不混入本批视觉修正。

## 回滚或恢复

- 页面顶部与卡片密度都是调用方局部改动，可按页面文件逐项回退；不要通过修改共享 Scaffold/Header 抵消。
- 水位校准回退时应恢复正式资源加载行为，而不是恢复已删除的复杂 Painter。
- 本地临时截图和 `.codegraph/` 均不是交付内容；跨环境只依赖 Git 中的源码、资源、测试和文档。
