# APP 后端、植物 DP116 与水位校准接入

> 文档类型：Historical Change Record
> 日期：2026-08-25
> 环境：Windows 本机
> 分支与起始版本：main / 9b057dc
> 范围：Flutter APP 后端账号、用户设备、植物、设备图片与涂鸦 DP 116/140
> 当前权威文档：`AI_CONTEXT.md`、`docs/COMMON_MODULES.md`、`docs/PRD_IMPLEMENTATION.md`、`docs/TUYA_SDK_SETUP.md`

## 背景与目标

根据后端完成清单与 Swagger，把国内账号、用户设备、植物和设备图片接入现有 Flutter/涂鸦链路；同时落实两个固件契约：水位校准按 0–3 顺序执行、取消用 5 且不用 4，以及植物绑定成功后把后台英文标识符写入可上报可下发的 DP 116。

## 变更内容

- 新增 `core/backend` Repository 与 DTO，封装短信、手机号密码/验证码登录、注册、产品与用户设备、植物目录/详情/绑定/删除、设备图片列表/上传/删除接口。
- 国内账号先由 APP 后端鉴权，密码按 Swagger 要求转为小写 MD5；后端返回 `userNo`、`tuYaPwd` 后继续建立涂鸦设备会话。APP Token 持久化并在鉴权失败、退出或涂鸦接力登录失败时清理。
- 用户设备按涂鸦 `deviceId` 查找后端 `userProductId`；新设备优先用后台 `broadcastId` 精确匹配涂鸦 PID，后台仅一个产品时允许唯一回落，多产品且无精确项时拒绝猜测。
- 植物页读取后端目录和详情，支持后端图片；更换植物先完成后端删除/新增，再把 `tuYaRemark` 下发 DP 116。DP 116 上报的已知值会反向更新 App 当前植物。
- 设备图片页进入时拉取后端列表，上传与长按删除调用后端；云端列表按设备隔离，内置动画使用 `builtin://` 标识，不计入用户文件数量。
- 水位校准最后的完成操作补发 `step3`，形成 `step0`、`step1`、`step2`、`step3`；取消以及在最终卡片尚未确认 `step3` 时关闭都发送 `step5`，不发送 `step4`。
- HTTP 调试日志补充 `tuYaPwd`、验证码、手机号和涂鸦账号脱敏；新增 `crypto` 依赖。

## 关键决策

- `API_BASE_URL` 未配置时使用禁用型后端 Repository，保留既有 Mock 与独立涂鸦开发流程，不隐式访问公网。
- 后端植物 `tuYaRemark` 是 DP 116 唯一数据源；数据库 id 和中文名不得下发。缺少英文标识符时直接阻止绑定。
- 后端绑定成功、DP 下发失败时保留绑定并提示用户重试，避免把已经成功的服务端写入伪装成完全失败。
- 设备图片云端管理与硬件 142/143/144 下发分开；本次不猜测尚未确认的 raw 文件协议。

## 外部操作

- 只读核验提供的 Swagger。`https://api.yikaltd.com/swagger-ui.html#/` 在本机返回备案阻断页；通过机器端口 `http://120.25.227.36:8601/v2/api-docs` 读取 Swagger 2.0 契约，没有使用真实账号、Token，也没有调用任何写接口。
- 只读对照同工作区兄弟工程的既有后端客户端约定和 MD5 实现；未修改其他仓库。
- 执行 `flutter pub get` 解析新增依赖。

## 未完成项与风险

- 后端 HTTPS 域名当前不可用，尚未执行真实 Token 下的端到端写接口或真机联调；机器端口 HTTP 仅用于读 Swagger，不能作为生产地址。
- 多产品后台必须维护 `broadcastId` 与涂鸦 PID 的准确映射，否则新设备不会自动建立 `userProductId`。
- 设备图片已进入后端云端列表，但 DP 142/143/144 的 URL 编码、文件限制与固件回执仍待后端/固件确认。
- 全量测试仍有旧 UI/Mock 断言失败和一个设备列表用例挂起；本次没有为迁就旧断言改动传感器演示数据、页面文案或导航测试壳，后续应单独建立测试基线治理任务。

## 回滚或恢复

- 回滚 `core/backend`、`FlowerpotState` 与三个页面的改动即可恢复纯涂鸦/Mock 流程；同时移除 `crypto` 依赖和相应测试。
- DP 116 回滚时必须同时恢复植物绑定文档与上报处理，不能只删下发代码留下错误契约。
- 水位校准回滚应恢复整个弹窗与测试，不得引入 `step4`。
