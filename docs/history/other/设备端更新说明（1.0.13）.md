## 1. 图片要求

### 1.1 上传图片必须满足（设备解码硬约束，逐条对应失败原因）

| # | 项 | 要求 | 依据 |
|---|---|---|---|
| 1 | 格式 | JPG Baseline（SOF0），禁止 Progressive（SOF2） | 设备解码器只认 SOF0 |
| 2 | 采样 | 4:2:0 | 设备解码器支持的最通用组合 |
| 3 | 尺寸 | 宽高 ≤2048（显示框为 320×240） | 解码器上限 2048；超框设备取左上 320×240 裁剪 |
| 4 | 宽高取偶 | `w &= ~1; h &= ~1` | RGB565 输出硬性要求宽度为偶数 |
| 5 | 文件 | ≤500 KB | 实际 320×240 JPG 约 15~60KB，此条为兜底 |

实测失败案例：`253048455.jpg` = 179×240，除宽度 179 为奇数外全部合格 → 设备解码直接失败、显示失败页（手机端无任何报错）。9:16 竖图 1080×1920 缩放取整会得到 135×240，同样中招。（设备端不做缩放）

## 2. 历史上报格式

### 2.1 触发时机

| 时机 | 上报内容 |
|---|---|
| 每 15 分钟采样后 | 每指标今天帧 1 条（N 随采样逐槽 +1） |
| 连云成功 / 全量查询 | 日历史每指标 7 帧（共 35 帧）+ 周 3 帧 + 月 6 帧（3 指标×2 段）全量补发 |
| 0 点滚动后 | 7 天全套重推 + 周/月全量 |

### 2.2 日历史帧（DP 131/134/137/164/165，raw）

**帧格式**（一条 raw 报告 = 一个自然日，每帧自带日期头，7 帧 = blk0 最旧一天 … blk6 今天）：

```
帧 = [年偏移(1B) 月(1B) 日(1B)] + 点序列
年偏移 = 年 - 2000（0x1A = 26 → 2026 年）
槽 k 对应时刻 = 该日 00:00 + k×15min
```

| 帧类别 | 点数 | len |
|---|---|---|
| 过去 6 天 | 定长 96 点 | 恒 **99B**（1B 点宽）/ **195B**（2B 点宽） |
| 今天 | 变长 N 点，N = 当前时刻槽+1 | **3 + N×点宽** |

**点编码**：

| DP | 内容 | 点宽 | 点值编码 | 定长帧 len |
|---|---|---|---|---|
| 131 | 水位·日 | 1B | mL÷2（0x4B=75 → 150mL） | 99 |
| 134 | 土壤湿度·日 | 1B | 整数 % | 99 |
| 137 | 光照·日 | 2B | lux，大端（0x0BB8=3000） | 195 |
| 164 | 空气温度·日 | 2B | 有符号×10，大端（0x0140 → 32.0℃；负温=补码 0xFF9C → −10.0℃） | 195 |
| 165 | 空气湿度·日 | 2B | ×10，大端（0x0258=600 → 60.0%）；帧长 3+2N 恒为奇数 | 195 |

**补 0 规则**：未采槽 = 0；整天无数据 = 96 个 0 照发一帧；今天帧只含已到时刻的槽（右端 = 当前时刻）。

**hex 示例**（某日已采 3 点）：

```
DP131 len=6:  1A 09 0F | 55 0F 57          → 170mL, 30mL, 174mL
DP137 len=9:  1A 09 0F | 1F 40 03 84 1F A0 → 8000, 900, 8100 lux
DP164 len=9:  1A 09 0F | 01 40 00 96 01 36 → 32.0℃, 15.0℃, 31.0℃
DP165 len=9:  1A 09 0F | 03 20 00 C8 03 16 → 80.0%, 20.0%, 79.0%
```

### 2.3 周历史帧（DP 132/135/138，raw）

```
帧 = [年偏移(1B) 月(1B) 日(1B) N(1B)] + N × 点
N = 环内有效天数（≤28，满 28 天滚动后恒为 28）
len = 4 + N×点宽
点序 = 最旧天 → 最新天；滚动覆盖后最后一点 = 最近聚合日
点值 = 当天日均值，编码同 2.2 对应指标
```

| DP | 内容 | 点宽 | 满帧 len |
|---|---|---|---|
| 132 | 水位·周（4 周） | 1B | 4+28=32 |
| 135 | 土壤·周（4 周） | 1B | 32 |
| 138 | 光照·周（4 周） | 2B | 4+56=60 |

### 2.4 月历史分段帧（DP 133/136/139，raw）

```
段帧 = [年偏移(1B) 月(1B) 日(1B) 段号(1B) 总段数(1B)] + 本段点
总点数 N ≤ 180（满 180 天滚动）；段 s 覆盖点 [s×90, min(N,(s+1)×90))
段 0 = 第 0~89 天（最旧在前）；N<90 时只有段 0（段 1 整帧不出现）
每段 len = 5 + 段点数×点宽
点值 = 当天日均值，编码同 2.2 对应指标
```

| DP | 内容 | 点宽 | 满帧 len |
|---|---|---|---|
| 133 | 水位·月（半年） | 1B | 每段 5+90=95，共 2 段 |
| 136 | 土壤·月（半年） | 1B | 每段 95，共 2 段 |
| 139 | 光照·月（半年） | 2B | 每段 5+180=185，共 2 段 |

段帧示例（已聚合 100 天）：

```
DP133 段0: 1A 09 0F 00 02 | 90 点（第 0~89 天）
DP133 段1: 1A 09 0F 01 02 | 10 点（第 90~99 天）
```
