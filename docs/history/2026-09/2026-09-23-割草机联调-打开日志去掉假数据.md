# 割草机联调：打开调试日志、去掉所有假数据

> 文档类型：Historical Change Record
> 日期：2026-09-23
> 环境：SSH 开发机
> 分支与起始版本：main / 55c0dae
> 当前权威文档：`docs/PRODUCT_RULES.md` §4.10、`AI_CONTEXT.md`

## 背景

用户：「现在要开始割草机和设备的联调，可以显示调试日志了，和以前一样有DPID的都打印进去，然后去掉所有假数据，都用真实数据。」

## 改动

1. **联调日志**：`DebugLogGate` 生产默认改回 `true`（2026-09-19 关的）。花盆与割草机的 DP 下发 / 上报 / 进页面读取照旧进日志框，没有新增记录点。
2. **割草机假数据全部删除**：
   | 原来 | 现在 |
   | --- | --- |
   | 设备列表最后一张「YSmower-01」卡、搜索页固定一行（`MowerDemo.enabled`） | 删掉；只从设备列表的真机进，`MowerHomePage.deviceId` 必填 |
   | `MowerDevice` 静态演示模式（本地模拟 DP5、「记忆」模拟、稿子初值：电量 78、雨淋 180 分钟、五区百分比…） | 删掉；初值一律「设备还没报」的中性值，之后按设备快照 / 上报 |
   | 长按电量环的模拟上报面板 | 删掉 |
   | 首页标题 / 设备参数名称 `YSmower-01`、型号 `YM-1200`、SN `YM202608240018` | 名称读涂鸦设备名；型号 / SN 没有数据来源，空着 |
   | 「恢复默认」下发稿子上的四块计划（`MowerDevice.defaultSchedule`） | 协议无默认计划：只记日志 + 提示，不下发 |
   | 消息通知 4 条写死的消息 + 写死日期「2026年8月31日」 | 日志 = `loadDeviceOperateLogs`（全部割草机 DP、30 天、100 条）；告警 = `loadDeviceMessages`（告警档）；提醒 = 空（无来源）；日期可选、按天过滤；下拉刷新 |
3. `mower_demo.dart` 改名 `mower_ui.dart`，只剩界面常量；`MowerDemoPlan.dayLabels/axisHours` → `MowerPlanAxis`。
4. 调试板默认设备改为当前打开的割草机，版本印子 `probe-v11`。

## 用例

`mower_pages_test.dart` 整份改成绑 Mock 割草机、断言 `publishedDps`；删掉依赖演示模拟的「记忆」用例（启动后的模式现在由设备上报）；
`mower_live_test.dart` 删「静态演示不下发」；`device_list_page_test.dart` 两条门禁用例合成「只列真实设备」，在线数 3 → 2；`debug_log_gate_test.dart` 改为默认开启。

## 验证

⚠️ 本机无 Flutter 工具链：analyze / test / 编译 / 真机全未跑。四个 Dart 静态自检（331 文件）通过；改动文件括号配平与改前一致；全仓 grep 无已删符号残留。
