## 帮助中心

割草机设置页一直传的是 `MowerDp.productId`，但 `loadFaqs` 只在后台 `getBasicData.deviceIdList` 里**找得到**它时才用，
找不到就退回列表第一个（花盆）——等于拿花盆的产品 ID 查割草机的帮助。改为：调用方指定了产品 ID 就一定用它，
日志里标「在 / ⚠️ 不在 deviceIdList 里」，并多打一行当前语言与整个 `deviceIdList`。花盆那条（不指定）口径不变。
⚠️ 接口要登录，本机没有登录态，线上数据没查；如果真机日志里 broadcastId 已经是 `mz7g3yzaufvoh4ls` 仍返回 0 条，
就要看后台那几条帮助挂的产品 ID 与语言。新增用例一条。

## 设备升级 / 删除设备 / 重新配网

- `mower_firmware.dart`：`upgradeMowerFirmware` 复用 `checkFirmware` / `upgradeFirmware` / `showFirmwareUpdateDialog` / `showOtaProgressDialog`，每步记联调日志。
- `MowerDevice` 收到 DP116 实时上报 "7" / "20" 时经 `failures` 弹提示。
- 删除设备：确认 → `removeDevice(id, resetFactory: false)` → 回首页。
- 「重新配网」从设置列表去掉（代码注释留着）。

## 计划页自适应

`MowerPlanChart` 纵轴不再写死 340：锚点改成比例（0 / 40/340 / 300/340 / 1），纵轴撑满父级剩余高度；
计划页按可用高度算卡片高度（减去上内边距、标题行、间距、空周提示、卡片底边距和 12 的留缝），不低于 430。
