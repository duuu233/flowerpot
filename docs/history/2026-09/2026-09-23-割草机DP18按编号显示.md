# 割草机 DP18 按编号显示

> 文档类型：Historical Change Record
> 日期：2026-09-23
> 环境：SSH 开发机
> 分支与起始版本：main / beed0cf

## 背景

产品：「DP18 上报的是 0，你显示的文案没有根据逻辑正确对接」，确认口径时回贴了文案表（键 0–12），并说「按这个显示啊」。

## 原实现与冲突

原来按**位图**解（协议 V2.3 §4.3「bitmap 13 位」、平台功能点表类型 fault）：0 = 无故障 → 显示稿子上的安全提示；左轮异常 = 1。
产品口径是**上报值 = 文案编号**：0 = 左轮异常。两者在「0」上正好相反。

## 改动

- `MowerFault.messageFor(value)`：按编号取文案；`MowerDevice.faultMessage` 改用它。位图的 `firstMessage` 留着。
- `faultBitmap` 改为可空：没报过 = null，不显示故障文案（否则初值 0 会被当成左轮异常）。
- 日志：上报 DP18 那行带「→ 黄条「…」」；进首页那行带文案。
- 用例：`messageFor` 三条；`mower_live_test` 期望改为编号口径。

## 待确认（固件）

没有故障时 DP18 报什么？如果也是 0，按编号显示会一直挂着「左轮异常」，需要固件和产品统一口径。

## 验证

⚠️ 本机无 Flutter 工具链：未编译、未跑用例、未真机；四个 Dart 静态自检 + 括号配平通过。

## 同日撤回：改回协议 V2.3 位图

产品：「按协议 V2.3 的来，0 表示正常就隐藏」。`faultMessage` 改回 `MowerFault.firstMessage`（位图），删掉 `messageFor`；
DP18 = 0 或没报过时首页黄条整条隐藏（稿子上的安全提示不再显示）；有故障位显示位序最低那条文案。新增页面用例：0 隐藏、1 显示左轮异常。
