# 割草计划无数据时的缺省态（不再画假数据）

> 文档类型：Historical Change Record
> 日期：2026-09-23
> 环境：SSH 开发机
> 分支与起始版本：main / 5f0d7cf

## 背景

产品：「割草计划如果没有数据上报 你这里要有的数据不能显示一个假的啊。首页今日计划这里保留日期和星期，下方内容给一个缺省提示“图标+暂无割草计划”。割草计划页面没有数据时不能做假的数据渲染。」

## 找到的假数据

1. **编辑框预填**：`MowerPlanDraft.forDay` 在那天没有时段时预填稿子上的 09:00–11:30 / 14:00–15:00，而且是**开着的**——点一下保存就把假时段下发给设备。
2. **首页今日计划**：没数据时画「今日无计划」「今日没有第二个时段」两行，不是产品要的缺省态。

## 改动

- 编辑框：空时段改为 `00:00–00:00` 且关着（`MowerPlanDraft._unset`），用户打开开关、选时间才算数；关着的不写进 DP101。
- 首页：只认设备会执行的时段（`validForDevice`）；一个都没有 → 日期星期照旧，下面「图标 + 暂无割草计划」（`mower-today-empty`）。第一段无效、第二段有效时，第二段顶上来当主时段。
- 计划页：一周没有时段 → 图表上方一句「暂无割草计划」（设备没报过 DP101 时加「设备还没有上报」），图表只画空坐标。
- 用例：新增一条覆盖三处。

## 验证

⚠️ 本机无 Flutter 工具链：未编译、未跑用例、未真机；四个 Dart 静态自检 + 括号配平通过。
