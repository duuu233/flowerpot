## V2.3 相对 V2.2 的变化

1. 新增 **DP110 schedule_reset**（bool rw，动作型自复位）：下发 true → 设备写默认计划（每天 09:00–11:30 + 13:30–17:30，组 0）→ DP101 自动上报 → 回写 false；查询全量恒 false。
2. 新增「开机门控」说明：自检完成前 DP18/DP111/DP5/DP2/DP3 不上报，完成后自动全量推一次；DP13/117/118 不受门控。App 侧不用改（本来就等上报）。
3. 雨淋三 DP 的说明补充（语义不变）。

## 改动

- `MowerDp.scheduleReset = 110`；`MowerDevice.resetSchedule` 下发 true，本地不改计划，等 DP101 上报；DP110 回写 false 正好消掉回显等待。
- 计划页「恢复默认」恢复确认框，确认后调 `resetSchedule`。
- 设备参数页改名：复用花盆的 `RenameDeviceDialog`（原 `_RenameDeviceDialog` 改公开）+ `state.renameDevice`（涂鸦改名 + 后端 `editUserProduct`）。⚠️ 后端那步只在后端设备表里有这台时才调（花盆同口径），没有就只改涂鸦。
- 型号 / SN：产品确认没有数据，保持空着。
- 用例：「恢复默认」改为确认 → 只发 DP110 → 模拟设备回报默认 DP101 → 周一两段 09:00–11:30 / 13:30–17:30。
