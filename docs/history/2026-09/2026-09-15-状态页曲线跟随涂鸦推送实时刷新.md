# 状态页曲线跟随涂鸦推送实时刷新

> 文档类型：Historical Change Record
> 日期：2026-09-15
> 环境：SSH（本机无 Flutter / Dart 工具链）
> 分支与起始版本：main / `9f7d444`
> 范围：`lib/src/state.dart`、需水 / 光照 / 空气温度 / 相对湿度四个状态页、`test/features/devices/status_history_live_test.dart`
> 当前权威文档：`docs/PRODUCT_RULES.md` §4.5；`AI_CONTEXT.md` 状态页与历史 DP 条目

## 背景与目标

产品：「再检查下，刚才提到的四个子页面的报表数据，会不会根据涂鸦推送的 DP 变化实时变动」。
上一轮（`2026-09-15-四个状态页按DP读取核对与光照历史改读137-139.md`）的未完成项里已记下「停留在页面时新到的
历史 DP 不会刷新曲线」。

## 核对结果

推送链路本身是通的：

1. 原生：Android `IDevListener.onDpUpdate`（`MainActivity.devListenerProxy`）、iOS
   `ThingSmartDeviceDelegate.device(_:dpsUpdate:)` 把本次变化的 DP 原样发到事件通道，raw 历史 DP 是十六进制串，不过滤。
   `onDevInfoUpdate` / `deviceInfoUpdate` 发整包快照。
2. Dart 仓库：`MethodChannelTuyaRepository._deviceUpdate` 把 DP 合并进快照，调 `_device(merged)` 重新解码
   131–139，更新 `_history[deviceId]` 与设备的 `history`。
3. 状态层：`_listenForDeviceUpdates` → `_applyDeviceUpdate` 替换设备 → `notifyListeners`，依赖 `FlowerpotScope`
   的页面全部重建。

| 页面内容 | 推送后会不会变（改之前） |
| --- | --- |
| 顶部实时值 / 状态（四页） | ✅ 会：每次 build 都从 `deviceById` 现读 |
| 需水状态曲线（131–136） | ❌ 不会：`history` Future 只在进页面、切日/周/月、切水位/土壤时取 |
| 光照状态曲线（137–139） | ❌ 同上 |
| 空气温度 / 相对湿度曲线 | 功能点表没有历史 DP，始终空态；推 112/114 只刷新顶部读数 |

## 变更内容

- `FlowerpotState.reportedHistory(deviceId, metric, range)`：设备快照里这一段历史。
- `FlowerpotState.historyReportedSince(deviceId, page, metric, range, before)`：与上次取曲线时的那一段比
  （`listEquals`），不同返回 true，并在帧后记一行「上报 ← [页面] 历史 DPxxx 有新数据（N点），曲线已刷新」
  （在 build 阶段被调，直接记日志会 notifyListeners 撞上 markNeedsBuild，所以用 `Future` 推到帧后）。
- 四个状态页：`_load()` 记下 `_loadedSeries`；`didChangeDependencies` 在已初始化后调 `historyReportedSince`，
  变了就 `history = _load()`。温度、湿度两页照同一套写（真机上快照里那一段恒为空，分支不会进）。
- 比的是**本页、本范围**那一段：电量上报、别的指标的历史变化都不会让曲线重取。
- 换 future 时 `FutureBuilder` 保留上一次的数据，不会闪回「正在读取」。
- 测试 `status_history_live_test.dart`：需水页推电量不重取、推 DP131 日包后曲线出现且记日志；光照页推 DP135
  （土壤湿度周包）不重取、推 DP138 后柱状图出现且记日志。

## 关键决策

- 不拿 112/114 的实时推送在 App 里攒成温度 / 湿度曲线：没有历史 DP 就是空态（`PRODUCT_RULES.md` §4.5），
  App 攒的点也会因退出页面、杀进程而断档，和设备历史包不是一个口径。
- 变化检测用设备快照里解出的序列，而不是 `changedDps`：`onDevInfoUpdate` 整包快照那条路 `changedDps` 为空。
