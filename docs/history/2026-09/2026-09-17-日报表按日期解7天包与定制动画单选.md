## 背景与目标

产品本轮四条：

1. 定制动画和纪念日图片按新要求裁剪压缩（JPG Baseline / 4:2:0 / ≤ 320×240 / ≤ 500 KB，等比缩放）。
2. 定制动画去掉没有选中时的多选框，只保留选中后的样式。
3. 定制动画去掉「支持多选」文字，代码层面限制成只允许单选。
4. 水仓水位、土壤湿度、光照、空气湿度、空气温度的日报表：DP 一次上报 7 天，App 按日期从包里解出
   对应值渲染，左右切日期限制 7 天（当天 + 往前 6 天）。

**第 1 条本轮没有代码改动**：同一天早些时候的 `e817468` 已经按这四条实现在
`lib/src/shared/media/upload_image.dart`，两处调用（`animations_page.dart`、`memorial_edit_page.dart`）
和单元测试都在，口径与产品这次贴的表逐条一致（含「等比缩放、不裁画面内容」）。本轮只做了核对。

## 变更内容

### 定制动画单选（第 2、3 条）

`lib/src/features/devices/presentation/animations_page.dart`

- 选中态 `final Set<String> _selected` → `String? _selectedId`。**多选在类型上就不成立了**，
  不是靠「点的时候记得把别的清掉」维持。点另一张＝换选中，再点当前这张＝取消选中。
- 新增 `_selectedFile(files)`：按 id 在当前列表里找那张，找不到返回 null。删除 / 刷新后列表会换，
  避免拿一个失效 id 去发 DP。
- `_deleteSelected` / `_pinSelected` 从「遍历选中集合」改成单个目标。`all`（走 DP156 全清）
  的判据从「选中数 == 文件数」变成「图库里只有 1 张」——单选之后这是唯一可能。
- 说明文字「支持多选，选中后可删除；长按可置顶」→「选中后可删除；长按可置顶」。
- `_GalleryTile` 的勾选圈改成 `if (selected)` 才画，未选中的格子不再画半透明空圈；
  选中那个挂 `Key('animation-tile-selected-<index>')` 方便断言。

### 日报表一次 7 天、按日期渲染（第 4 条）

`lib/src/tuya/tuya_history_codec.dart`

- 新增 `DailyHistorySlice`（年偏移 + 月 + 日 + 那天的点，`dayKey` 是 `MM-DD`）、

- 新增 `TuyaHistoryCodec.decodeDaily`：依次试三种布局，每种都要过日期头校验。
- 新增常量 `maxDailyWindow = 7`。

`lib/src/state.dart`

`lib/src/features/devices/presentation/reports_page.dart`

- 空态文案拆成三句（没有历史 DP / 日包里缺这一天 / 整条 DP 还没到过），抽成 `_emptyMessage`。
- 曲线右端标签：翻到过去某天是 `23:45`，今天仍是「当前」。

## 关键决策

- **7 天帧按帧长认，不写死。** 09_12 功能点表的日帧仍是单天「3 字节头 + 96 点」，新固件的 7 天
  布局没有文档。产品确认走「按帧长自动判、两种都支持」，和仓里 164 / 165 认帧头是同一个套路。
  两种布局的帧长撞不上（点宽 1：99D vs 675；点宽 2：195D vs 1347），认出长度后再用日期头
  （月 1–12、日 1–31、逐日连续，升降序都认）校验——**光看长度不够**，一段点数据凑出合法帧长的
  概率不低。拿到新版功能点表后把 `decodeDaily` 收成认死的那一种即可，调用方不用动。
- **日期键不含年。** 日期头第一个字节是「年偏移」，基准年（2000 还是别的）功能点表没写；
  7 天窗口里 (月, 日) 不会重复，所以匹配按 `MM-DD` 走，年偏移只打进日志。
  只有「一个帧头 + 多天连排」那种布局需要真年份做进位，那里按涂鸦惯例取 2000 + 年偏移，
  影响面只有 2 月末怎么进位。
- **`series(metric, day)` 保持「最新那天」。** 这样状态页、首页、实时推送接点那一整套逻辑
  （`chartSeries` / `_recordLiveSamples`）一行都不用改，7 天包只是多了一份按天的副本。
- **切换窗口固定 7 天，到边禁用而不是翻到空页。** 窗口外设备根本没上报，能翻过去只会让人
  以为数据丢了。
