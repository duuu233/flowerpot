# 取消配网二次确认；首页帮助中心入口、使用帮助卡与今日养护轮播

> 文档类型：Historical Change Record
> 日期：2026-09-14
> 环境：SSH（本机无 Flutter / Dart 工具链）
> 分支与起始版本：main / `6e03257`
> 范围：配网进度组件、首页快捷列表 / 帮助卡 / 今日养护、设备设置页、`FlowerpotState.loadFaqs`、新增图标 `help_center_icon.png`
> 当前权威文档：`docs/PRODUCT_RULES.md` §1.6、§4.3

## 需求

1. 配网中点「取消配网」要二次确认，内容「当前设备正在配网中，确定是否取消」；
2. 首页（已绑定植物）：首次使用指南去掉点击跳转、纯文本；帮助中心移到电池状态下方；同步帮助中心图标风格；
3. 今日养护右边文案改为文字滚动轮播，不要渐变；
4. 帮助中心后台有 1 条数据却不显示——排查。

## 变更与决策

- **确认框画在 `PairingProgressView` 里，不弹路由。** 配网随时可能在框开着时结束，配网页随即
  `pushReplacementNamed`，它替换的是最上层路由——框若是路由，被替换掉的是框，配网页留在成功页底下。
  内嵌 `AppDialog`（该组件本就注明可嵌入自绘遮罩的页面）+ `ModalBarrier` + `PopScope`（返回键只关框）。
  按钮「继续配网」/「取消配网」：默认的「取消」在「确定是否取消」的框里有歧义。搜索页「连接设备」段共用该组件，一并生效。
- **帮助中心移到首页快捷列表**（`HomeActionKind.help`，电池状态下方），不过设备在线门禁；设备设置页那一行删除（「移动」）。
- **图标**：另外三个是 80×80 浅色圆角底 + 青色 `#70AFB5` 实心图形；设置页用的描边问号风格不符。无图像库，
  用纯 Python 解/编 PNG：底板取三张图逐像素的公共底，图形取 `help_chat_icon.png` 的气泡（同一青色、问号本就透明），
  4×4 超采样缩到 38px 居中合成，得到 `help_center_icon.png`。已目视核对与另三张一致。
- **首页帮助卡** `HomeHelpCard` 去掉 `onTap`。
- **今日养护**：`AnimatedSwitcher` 只留 `SlideTransition`，按 key 区分进出方向（进 +1→0、出 0→-1），
  整格高度滚动，`ClipRect` 裁掉格外部分；时长 900ms、间隔 8 秒不变。
- **帮助中心不显示**：App 调的就是 `GET /Client/Product/getProductFaqList`，header 带 `language`（简中=2），
  query 带 `pageIndex=1&pageSize=50&broadcastId=<当前设备涂鸦产品ID>`；返回的 `pageData[].faqTitle/faqContent`
  解析正确。无法用账号实调（无 token），但从管理后台（flowerpot-web）表单看：**新增常见问题时「选择语种」默认英语(1)、
  「所属产品」默认全部(0)**——按默认值保存的记录在简中 App 下会被语种筛掉，全局问题是否会被 `broadcastId` 筛掉取决于后端。
  客户端只补了一处：后端登录态失效时原来静默返回空、不发请求也不记日志，现在记「帮助中心 ✗ 未请求 …」。
