# 搜索页设备图标按产品区分

> 文档类型：Historical Change Record
> 日期：2026-09-23
> 环境：SSH 开发机
> 分支与起始版本：main / 376fbd6

## 背景

用户：「搜索设备页面，设备的图标换一下，花盆的和割草机的不一样，割草机是静态的，现在去掉了，但是图标是对的，花盆也找自己的图标替换一下」。

## 改动

搜索结果每一行左边原来是蓝牙 / 热点小图标（`Icons.bluetooth` / `Icons.wifi_tethering`），改为按产品画稿子（`docs/UI/v2/割草机/选择设备.png`）上的 40 圆角方块：

| 产品 | 判断 | 图 |
| --- | --- | --- |
| 割草机 | BLE 广播 pid == `MowerDp.productId` | `mower_list_icon.png`（原静态行用的那张） |
| 花盆 | pid == `TuyaConfig.productId` 或 `broadcastId`；热点行（AP 回落只有花盆） | `device_planter_icon.png`（设备列表空态用的同一张） |
| 其它（排查态列出的别家设备、后台新加未配图的产品） | — | 退回原来的蓝牙 / 热点图标 |

割草机那张 150×150 的画布里方块只占左上 120×120（稿子连画布导出），所以按 50 画、上移 5，方块与花盆同为 40。

## 待确认

割草机的**广播** pid 是否就是平台 ID `mz7g3yzaufvoh4ls`（花盆的广播 ID 与平台 ID 不同）——不是的话割草机会落到「其它」，要补进判断。
