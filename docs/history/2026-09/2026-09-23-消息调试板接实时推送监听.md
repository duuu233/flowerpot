# 2026-09-23 消息调试板接实时推送监听

## 背景

产品在涂鸦后台打开了设备消息推送：条件「电量（DP）> 0」，推送给用户、在设备消息监控中接收，
推送方式「消息中心」。要在调试板上接收这类推送，看有没有类型区分。

## 做了什么

- 解包 `thingsmart-personallib` / `thingsmart-device-api` 7.5.1：`ThingHomeSdk.getPushInstance()` → `IThingPush`，
  `registerPushAlarmListener` 收 MQTT 802（`MQ_802_PushAlarmBean {type, msg}`），`registerMQPushListener` 收 MQTT 52
  （`MQCompensationBean {type, link, timeStamp}`）。详见 `docs/TUYA_CAPABILITY_AUDIT.md` 5.5。
- 安卓桥接 `startPushListen`：两路各挂一个动态代理，收到就把对象全部字段经事件通道推上来（`type=pushMessage`）。
  SDK 没有注销方法，进程内只注册一次。
- Dart：`TuyaRepository.startPushListen()` / `pushMessages`，`FlowerpotState.startPushListen()` / `pushMessages`，Mock 同步。
- 调试板（割草机「消息通知」页底部）加「开始接收推送（实时）」：逐条打印时间、来源、bean 类名和全部字段，
  `msg` 为 JSON 时展开；顶部按 `来源/type` 计数。复制全部也带上这段。版本印子 `probe-v10`。

## 怎么测

1. 进割草机「设置 → 消息通知」，拉到底部调试板，点「开始接收推送（实时）」，看「已注册」有两项。
2. App 保持在前台，让绑在本账号下的设备上报一次电量（DP 103）。
3. 看调试板有没有新条目、`type` 取什么值；再点「拉取涂鸦消息」对照消息中心里那条的 `msgType` / `msgCode` / `alarmType`。

## 验证与限制

- 本机无 Flutter 工具链：analyze / test / 编译 / 真机全未跑；四个 Dart 静态自检 + `kt_dangling_refs` + 括号配平通过。
- 推送只在 App 前台（MQTT 连着）时收得到；系统推送通道（`registerDevice`）没接。
- iOS 未接。
