# 打包失败：三元分支里的空安全下标 `?[`

> 文档类型：Historical Change Record
> 日期：2026-09-15
> 环境：SSH（本机无 Flutter / Dart 工具链）；报错来自 Windows 上 `compileFlutterBuildRelease`
> 分支与起始版本：main / `3691d35`
> 范围：`lib/src/state.dart`、`tools/dart_ternary_null_index_check.py`、`docs/PRODUCT_RULES.md`
> 当前权威文档：`docs/PRODUCT_RULES.md` §5 实现底线（自检脚本清单）

## 背景与目标

`3691d35`（状态页曲线推送即往前移动）打 release 包失败：

```text
lib/src/state.dart:2033:27: Error: Expected ':' before this.
        : const <double>[];
lib/src/state.dart:2032:23: Error: A value of type 'Map<SensorMetric, List<double>>?' can't be assigned to a variable of type 'bool'.
        ? _liveSamples[deviceId]?[metric] ?? const <double>[]
lib/src/state.dart:2034:43: Error: An expression whose value can be 'null' must be null-checked before it can be dereferenced.
```

## 根因

`FlowerpotState.chartSeries` 里写了 `cond ? _liveSamples[deviceId]?[metric] ?? const <double>[] : const <double>[]`。
三元分支里的 `?[` 被解析器读成「`_liveSamples[deviceId]` 作条件的嵌套三元 `? [metric] ?? …`」，于是找不到配对的 `:`，
后面几条类型错误都是这一处误解析的连带结果。括号配平、字符串、私有成员、可空返回值四个自检都查不到这种语法歧义。

## 变更内容

- `state.dart`：先取 `final liveByMetric = _liveSamples[deviceId];`，条件里判空，分支里只写 `liveByMetric[metric] ?? const <double>[]`；原处留注释。
- 新增 `tools/dart_ternary_null_index_check.py`：去掉字符串和注释后，查以 `? ` 开头的三元分支行、或同一行 ` ? … ?[ … : ` 里出现的 `?[`。
- `PRODUCT_RULES.md` 自检清单加上这一条。

## 验证结果

- 新检查器对 `3691d35` 的 `state.dart` 报出 2032 行（与编译器一致）；修复后全库 290 个 Dart 文件零报。
- `dart_dangling_refs.py`、`dart_nullable_await_check.py`、`dart_string_check.py`：OK。
- ⚠️ 仍未在本机编译；需要 Windows 那边重新打包确认。

## 未完成项与风险

- 检查器是按 dart format 排版的启发式，三元写成别的排版（例如分支和 `?` 不在同一行开头）可能漏报。

## 回滚或恢复

不需要回滚：只改了一处写法与自检脚本。
