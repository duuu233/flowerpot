# 花盆APP 改动说明（2026-11-27）

## 一、重新配网后，自定义纪念日不显示

**问题**：设置自定义纪念日后，用「重新配网」重新连上设备。设备上的纪念日还在，App 里却看不到。「移除设备再添加」没有这个问题。

**原因**

- App 原来只按「设备 ID」去服务器查纪念日，设备联网后报上来的纪念日一概不看。
- 最可能的情况是：重新配网后，涂鸦给设备换了新的设备 ID。服务器上的纪念日还记在旧 ID 名下，按新 ID 查不到。

**改了什么**

1. 设备联网后报上来的纪念日，App 会拿来对照，列表里缺的自动补回来。标题、内容以服务器上的记录为准。
2. 服务器上的记录还挂在旧设备 ID 名下时，自动改挂到当前设备，以后进纪念日页就能直接看到。
3. 服务器上已经没有、只有设备上还有的，按设备上的内容重新建一条。标题暂显示「自定义纪念日」，可以再改。
4. 重新配网前后设备 ID 变了、但确认是同一台花盆时，纪念日整体搬到新 ID 下。
5. 删除、编辑纪念日照旧：刚删掉的不会被补回来，保存后也不会多出重复的一条。

## 二、设备名称

**1. 修改设备名称（只核查，未改动）**

App 改名用的是涂鸦 SDK 自带的改名功能，安卓、苹果都调用正确。

**2. 名称后面多出数字（如「花盆test4」）**

- 这个数字是涂鸦在设备激活时自动起的：同一账号下已有同名设备，新激活的就加一个序号，不是 App 加的。
- 每重新配网一次就重新激活一次，所以数字会往上跳，之前改过的名字也会被涂鸦重新起的名字覆盖。这时 App 显示产品名称。
- 11-26 已改：设置页顶部原来直接显示涂鸦起的名字（带数字、时有时无），现在和设备列表、首页显示一致。

**3. 是否是授权码 / 绑定关系问题**

App 联调日志里新增每台设备的设备 ID、uuid（设备的授权标识）和激活时间，可以这样判断：

- 两台不同的花盆 uuid 相同：授权码重复，涂鸦会把它们当成同一台设备，需要设备端 / 模组厂核查。
- 同一台花盆重新配网后设备 ID 变了：属于重复激活。名称数字跳动、纪念日查不到都是这个原因。
