# 割草机协议 V3.0 更新报告（2026-10-22）

> 依据：《DP协议对接_V3.0》《拒绝理由与文案_V1.0》。已推送 main。**开发环境没有 Flutter，测试未运行，未真机验证。**

## 1. 对接的 DPID

- 新文档的 DP 编号与原来一致，不需要改号。
- 新增 DP120「事件码」：目前只记录在联调日志里，界面上不显示。
- 联调日志里显示的 DP 名称已按新文档更正，包括充电状态（DP117）和工作时间（DP119）。
- 「恢复默认计划」的说明改为新默认值：每天 08:30–12:00 和 14:00–18:00，周一 / 三 / 五修边。

## 2. 状态显示：严格按设备上报

- 首页状态只显示设备报的工作状态，一个值对应一个词。
  - 「在桩等待充电」「在桩等待雨停」分开显示，不合并成「回桩」。
  - 设备报「关机」时显示「关机」（原来显示的是「休眠」）。
- 机器日志不再自行推断「作业结束」「已回到充电桩」；低电量时只记录电量，不再预告「即将回充」。
- 设备没在充电时不显示充电文字，这条保持不变。

## 3. 拒绝提示

- 提示文字全部按《拒绝理由与文案 V1.0》改，中文和英文都改了。
- 三种在桩等待的提示各自独立：
  - 有雨：「雨天暂停中，雨停后自动继续」
  - 电量不足 70%（新增）：「机器电量小于70%，已进入充电等待」
  - 其它情况：「机器在桩等待中」
- 设备内部写入失败时，提示「操作未生效，请重试」（原来不提示）。
- 没有归类的拒绝，提示里会带上拒绝码。

## 4. 暂停 / 继续按钮

- 机器在桩等待充电时，「停止 / 继续」按钮置灰，点击不会下发指令。
- 同日经确认，**在桩等待雨停时也一起置灰**。

## 5. 交互

- 按文档说明，在桩等待时停止和继续都不起作用，所以把按钮置灰。
- 文档里写「无需重发」的情况，APP 本来就不会自动重发，所以交互没有其它改动。
- 弹窗样式保持原样。

## 6. 文档

- 旧文档已由用户移到 `docs/history/other/`。
- 文档导航 `docs/README.md` 已按当前两份协议文档重建。
