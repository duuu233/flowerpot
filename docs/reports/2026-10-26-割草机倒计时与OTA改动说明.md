# 割草机倒计时与 OTA 说明（2026-10-26）

## 一、倒计时（按 DP121）

- **计算**：设备上报 DP121（计划开始、计划结束、机器当前时间），倒计时 = 计划结束 − 机器当前时间，手机上按分钟递减；机器每分钟重发一次，收到即校正。
- **启动时**：工作时间（DP119）发送成功后，立即显示计时图标，时间处转圈；收到设备新计划后显示剩余时间。设备一直不报新计划（例如启动被拒）时，最多转圈 60 秒。
- **隐藏**：只在剩余为 0 或设备报无计划时隐藏，与机器状态、在线与否无关。

关键点：
- 机器真正开始计划才有倒计时，被拒或没启动不显示；多台手机显示一致；改手机时间不影响。
- 刚进页面读的是云端缓存，可能多显示不到 1 分钟，下一次上报后校正。
- **需要带 DP121 的固件（2026-10-26 起）**，旧固件不显示倒计时。

## 二、OTA 提醒

设置页 OTA 进度层开着时，不弹任何 OTA 提醒（固件升级提醒、割草机「拒绝升级」「升级失败」提示），结果由进度层显示；进度层关闭后提醒按原规则判断。

## 三、OTA 日志怎么用

1. 安装**联调包**（正式包不记录）。
2. 正常操作 OTA 升级，日志自动记录，无需设置。
3. 出问题后：App 左下角联调日志 → 点 **「OTA日志」** → 选微信 / QQ / 邮件发送。
   - 发出的是一个 `ota-log-日期_时间.txt`（最近 7 天合并），手机上可直接打开；
   - 发到微信「文件传输助手」或 QQ「我的电脑」，电脑端即可打开。
4. 同时告诉开发失败的大致时间。

日志按时间记录四类内容：`[native]` SDK 原始返回、`[sdk]` App 收到的事件、`[app]` App 的判断、`[ui]` 界面显示与用户操作，用来判断问题出在设备 / SDK、原生桥接还是 App。只记设备 ID 末 6 位，不记账号密码。
备用取法（连电脑）：`adb pull /sdcard/Android/data/com.common.yikaltd/files/ota_logs/`。



##  四、验收要点

1. 自动启动选 2 小时：先转圈，随后显示约「2小时0分」，到 0 消失。
2. 盖子打开时启动被拒：转圈结束后不显示倒计时。
3. 作业中进入待机 / 离线：仍有剩余就继续显示；另一台手机打开显示相同时间。
4. OTA 进度层打开期间：不出现升级提醒或割草机升级失败提示。
5. 做一次 OTA 后点「OTA日志」分享到微信：手机和电脑都能打开，能看到四类记录。
