# 读取数据不缓存、不延时（2026-10-21）

> 分支 main，花盆与割草机共用。代码与单测已改；**开发环境没有 Flutter 工具链，测试未运行，未真机验证**。
> 规则原文：[PRODUCT_RULES §4.26](../PRODUCT_RULES.md)；同日第一轮（OTA 核验与 SDK 去缓存）见 [OTA结果与SDK实时读取](2026-10-21-OTA结果与SDK实时读取.md)。

## 1. 口径

用户：「所有读取到的数据不做任何缓存、延时等机制，原始赤裸，及时展示在 APP 页面」。
范围包括**涂鸦 SDK 数据**和 **APP 后端接口数据**。

## 2. 现在每类数据怎么读

| 数据 | 来源 | 什么时候读、怎么显示 |
| --- | --- | --- |
| 设备 DP 实时值 | 涂鸦推送 | 到达即显示 |
| 设备清单 | 涂鸦云（家庭详情） | 登录、回前台、下拉刷新现拉；查询期间到的推送逐项叠加，不退回旧快照 |
| 在线状态 | 涂鸦推送 + SDK 设备模型 | 推送即显示；前台每 3 秒再对一次，补漏 |
| 割草机页面 DP | SDK 当前设备模型 | 进页现读，实时上报直接更新 |
| 固件新版本 | 涂鸦检测升级 | 每次点入口现问；提醒在进页、重新上线、版本变化时重查 |
| OTA 进度 | SDK 推送（Android 另有 3 秒兜底查询） | 收到当帧显示 **（本轮去掉 98% 停 0.9 秒）** |
| OTA 结果 | 现读 SDK 当前设备版本 | 进入安装、核验、推送、轮询时现读 |
| 设备型号 | 涂鸦 | 每次进页面现问 |
| 消息通知 | 涂鸦消息中心 | 进页拉；**收到推送立即拉，2 秒后再补拉一次（本轮）** |
| 植物资料 | 后端植物目录 | **进首页、设备换报 DP116、弹引导窗时现拉（本轮）** |
| 纪念日（自定义） | 后端 | **进页现拉；失败显示重试，不显示本机旧列表（本轮）** |
| 协议、隐私、平台邮箱、产品 ID | 后端基础数据 | **每次使用都现拉（本轮）** |

## 3. 本轮改了什么

| 位置 | 之前 | 现在 |
| --- | --- | --- |
| 消息页收到推送 | 先等 2 秒再拉 | 立即拉；2 秒后再补拉一次（云端入库可能比推送晚）；并发查询只让最后一次落到页面 |
| OTA 进度弹层 | 走到 98% 先停 0.9 秒再切「固件安装中」 | 收到当帧就按 SDK 阶段显示 |
| 植物资料 | 目录里已有就不拉；查不到的 ID 本次登录不再查 | 每次现拉；后台改了图片、名称，重进首页即更新 |
| 设备换报一株目录里没有的植物 | 继续显示上一株 | 显示「植物资料暂未获取」，补拉到就换上 |
| 纪念日（接了后端） | 先显示本机存的列表；拉取失败继续显示旧的 | 只显示本次拉到的；加载中显示加载，失败显示「纪念日加载失败」+ 重试 |
| 基础数据 | 拉到一次就复用（只有「我的」页强制重拉） | 协议页、「我的」页、开始扫描时都现拉 |

## 4. 保留的机制及原因

- **写入回显保护（用户确认保留）**：显示页亮度松手后最多 5 秒等设备回报；割草机下发后 5 秒内整包快照不覆盖该 DP；普通设置下发成功后先显示下发值。设备实际上报的 DP 照常即时显示。去掉会重新出现亮度滑块回跳。
- **轮询和补拉**（在线 3 秒、Android OTA 3 秒、消息 2 秒补拉）：都是「多读一次」，不推迟显示。
- **拉取失败时**：植物资料、基础数据保留本次登录上一次拉到的内容，页面不变空（协议页另有 App 内置文案兜底）；纪念日显示失败和重试。
- **历史曲线分帧缓冲**：设备一包只发一帧，日 7 帧、月 1～2 段，必须攒齐才能画。
- **家庭 ID 记忆**：只决定查哪个家庭，设备清单仍每次现问涂鸦。
- **配网第三步停 1～2 秒**：产品要求的流程感，与数据读取无关。

## 5. 未改、需要另行确认

- 花盆设备**从未上报过**某个 DP 时，传感器数值目前按 0、设置项按出厂默认显示（割草机电量已显示「—」）。这是「没有数据」怎么显示的问题，不是缓存；如需统一改成「—」请确认后另做。
- 后台从植物目录里**删除**某株，或改了它的涂鸦标识时，本次登录内旧条目仍可能匹配，重新登录后消失（目录接口分页，不能整表替换）。

## 6. 真机验收

1. **消息**：开着消息页让设备触发告警，推送到达后列表马上刷新；首拉还没有的，2 秒内补上。
2. **OTA**：升级进度走到 98% 时，弹层立刻显示「固件安装中」。
3. **植物**：后台改植物图片或名称，重进首页即显示新内容；设备换一株后台没配的植物时，显示「植物资料暂未获取」，不再显示上一株。
4. **纪念日**：断网进纪念日页，显示「纪念日加载失败」和「重试」；恢复网络点重试，显示后台最新列表。
5. **协议、邮箱**：后台修改后重新进页面即生效，不用重启 App。
