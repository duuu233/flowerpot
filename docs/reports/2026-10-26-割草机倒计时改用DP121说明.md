# 割草机倒计时改用设备当前计划（DP121）说明（2026-10-26）

> 依据：协议 V3.0（固件基线 2026-10-26）§3.8 DP121 `schedule_current`。
> 状态：已实现，**未编译、未运行测试、未真机**（本机无 Flutter）。

## 一、改了什么

倒计时不再由 APP 自己按「工作时间（DP119）发送成功」开始计时，改为**完全按机器上报的当前计划**：

- 机器发 DP121：计划开始时间、计划结束时间、机器此刻时间。
- APP 收到后用「结束 − 此刻」算出剩余，之后在手机上逐分钟递减；机器每分钟兜底重发一次、或计划变化 / 校时时重发，APP 收到就按新数据校正。
- 机器报「无计划」（任务结束、取消）时倒计时收起。

## 二、解决了原来哪些问题

| 原来的问题 | 现在 |
| --- | --- |
| 点了确认，但盖子没合、离线、发送失败、过 18:00 等，倒计时不出现或停在旧值 | 只要机器真正开始了计划就出现，没开始就不出现 |
| 启动被设备拒绝，倒计时照样走 | 机器没有计划就不显示 |
| 另一台手机启动、换手机、重装后不显示 | 任何手机都按机器上报显示，一致 |
| 改手机时间，倒计时跟着跳 | 用的是机器给的「结束 − 此刻」差值，与手机时间无关 |
| 面板或割草计划自动启动的作业没有倒计时 | 机器有当前计划就显示 |

## 三、不变的规则

- 显示位置和样式不变：状态胶囊里「⏱ X小时Y分」，按分钟递减，到点停在「0分」，直到机器报无计划才收起。
- 待机、休眠、已关机、离线时仍隐藏（2026-10-24 口径），回到其它状态按原结束时间接着显示。
- 启动流程（安全提醒 → 选时长 → 发 DP119 → 启动）不变，DP119 仍下发给机器作为本次作业时长。

## 四、已知边界

1. **刚进页面时读到的是云端缓存的最后一帧**：机器在线时最多晚 60 秒（兜底周期），可能多显示不到 1 分钟，下一帧到达即校正。
2. **启动后要等机器报 DP121 才出现**：通常是立即上报；旧固件（2026-10-26 前）没有 DP121，**倒计时不再显示**，需升级固件。
3. 启动瞬间机器状态若仍是「待机」，倒计时会在状态变成割草后才显示（按待机隐藏规则）。

## 五、真机验收

1. 合盖点「自动」选 2 小时确认：机器启动后状态胶囊出现「2小时0分」左右，联调日志有「倒计时 · 割草机 DP121 … 计划 HH:MM–HH:MM」。
2. 盖子打开时启动：被拒，不出现倒计时。
3. 另一台手机打开同一台割草机：显示相同剩余时间。
4. 作业中点停止 / 取消回待机：倒计时隐藏；机器报无计划后不再出现。
5. 改手机系统时间：倒计时不跳。
