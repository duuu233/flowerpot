# 割草机首页手动计划与今日计划改动说明（2026-10-30）

依据协议 V3.0（V3.1 增量）与《DP121 计划类型 App 对接说明 V1.0》：DP121 新增计划类型 `t`（0 无计划 / 1 定时计划 / 2 手动计划）。

## 一、DP121 计划类型

- 读取 `t`；旧固件（≤ 1.3.4）没有该字段，按 0 处理，照常显示倒计时与今日计划。
- 判断「计划是否变化」改用开始、结束、类型三项，同一时段只是类型从定时变手动也会刷新。

## 二、首页

- 状态（待机 / 割草中…）后面不再显示倒计时。
- 计划卡标题：倒计时为 0 直接显示「今日计划」，不看类型；倒计时大于 0 时，手动计划（`t=2`）显示「手动计划」，其余显示「今日计划」。
- 倒计时移到计划卡里原「修边」的位置；隐藏规则不变，只看 DP121 算出的剩余为 0。工作时间下发后的转圈也在这里。
- 手动计划：日期星期读手机；起止时间取 DP121 的开始、结束；不显示修边。
- 今日计划：时段仍来自割草计划（DP101）；两个时段统一为原「下一任务」的字号和颜色，去掉「下一任务」文字；每个时段后按手机时间显示「未开始 / 进行中 / 已结束」；「修边」移到「今日计划」文字后面。
- 手动计划倒计时走完后自动切回今日计划；时段开始 / 结束、过零点时进度和日期自动更新。

## 三、需要平台确认

DP121 数据长度上限需改到 64 字节以上，否则带 `t` 的上报会被截断、整条无法解析。

## 四、花盆：自定义图片与首次水位校准（2026-10-31 追加）

- 术语：「定制动画」统一改称「自定义图片」，包括首页入口和页面标题。
- 自定义图片页提示：在「长按文件可删除已选文件」下面新增两条——「设备中间按键可长按退出和进入」「左右触摸可以切换自定义图片」。
- DP169 `first_calib`（bool，默认 false）：设备首用或恢复出厂后配网成功，先走教程，再自动水位校准；完成、跳过或退出校准界面任一发生即上报 true，恢复出厂清回 false。App 只在 DP169 为 true 时进入设备页，否则停在设备列表，提示「请先在设备上完成使用教程与水位校准」。没上报过 DP169 的旧固件同样进不去。
- 原「DP169 文件分片下载」作废，App 没有接过，不受影响。
- SD 卡更新类型共三种：表情动画（.mjpeg）、植物映射（.json）、节日素材（.mjpeg）。App 不参与，由花盆后台公用文件选择。
