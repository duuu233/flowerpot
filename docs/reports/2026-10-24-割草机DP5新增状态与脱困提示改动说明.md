# 割草机 DP5 新增状态与脱困提示改动说明（2026-10-24）

> 依据：协议 V3.0（2026-10-24 更新版）。
> 相关提交：fc3e0dd（DP5 新增三种状态）、12191c3（首页黄条脱困提示改跟 DP5）、445a11e（倒计时在待机 / 休眠 / 关机（离线）时隐藏）。
> 状态：已推送；**未编译、未运行测试、未真机验证**。

## 一句话

设备新报的「陷坑脱困中 / 低电回充中 / 雨滴回充中」首页都能显示了；首页黄条「机器陷入坑洼，正在脱困」改成跟着工作状态走，不会再漏提示或提前消失；工作时间倒计时在机器待机、休眠、关机（离线）时隐藏。倒计时什么时候开始计时不变。

## 改了什么

### 1. 工作状态新增三种（fc3e0dd）

| 设备报 | 首页状态显示 | 之前 |
| --- | --- | --- |
| 12 | 陷坑脱困中 | 认不出，停在上一个状态 |
| 13 | 低电回充中 | 同上 |
| 14 | 雨滴回充中 | 同上 |

- 普通回充仍显示「回桩中」，到桩后仍是「在桩等待充电 / 在桩等待雨停」，不变。
- 以前定稿的「回桩途中要分雨滴还是正常」，设备现在直接报 13 / 14，这一项随之落实。
- 故障位（DP18）文档没有变化，APP 原本就与文档一致，未改。
- 回充事件码（51~53）不用于显示：协议写明回充原因以工作状态为准。

### 2. 黄条「正在脱困」改跟工作状态（12191c3）

| | 之前 | 现在 |
| --- | --- | --- |
| 什么时候显示 | 收到脱困开始事件（只发一次） | 工作状态是「陷坑脱困中」（设备每秒重报） |
| 什么时候收起 | 收到脱困结束事件，或 2 分钟到时 | 工作状态变成别的（脱困成功回割草、困死变故障、按急停变急停） |
| 事件那一帧丢了 | 不提示 / 一直挂到 2 分钟 | 不受影响 |
| 脱困途中才打开首页 | 不提示 | 直接显示 |
| 脱困超过 2 分钟（设备最长 180 秒） | 提前消失 | 一直显示到结束 |

- 黄条和首页状态现在说的是同一件事：状态写「陷坑脱困中」时，黄条同时提示「机器陷入坑洼，正在脱困」（按产品确认两处都保留）。
- 显示优先级不变：已关机 > 设备故障 > 设备已抬起 / 已落地 > 正在脱困。脱困失败后照旧显示「机器被困，请移至平坦区域。」
- 抬起 / 落地提醒不受影响。

### 3. 倒计时在待机、休眠、关机（离线）时隐藏（445a11e）

按产品口径，下面任一情况成立，首页状态胶囊后面就不显示倒计时：

| 产品说法 | APP 判断依据 | 胶囊显示 |
| --- | --- | --- |
| 待机 | 工作状态 DP5 = 0 | 待机 |
| 休眠 | 工作状态 DP5 = 2（协议文字为「关机」） | 关机 |
| 关机 | DP113 上报已关机，且之后没有再开机 | 已关机 |
| 离线 | 设备在线状态为离线 | — |

- 「休眠」「关机（离线）」与设备的几个信号不是一一对应，所以 DP5 = 0、DP5 = 2、DP113 已关机、离线四种都隐藏。
- 只是不显示，倒计时终点保留、照常走；离开这些状态后按原终点接着显示，这时可能已经少了一截或为「0分」。
- 其余状态照旧显示：割草中、停止、故障、回充（含低电 / 雨滴回充中）、在桩等待、陷坑脱困中等。

## 没改的

- 停止 / 继续、自动 / 定点 / 回归按钮能不能点的规则不变；脱困中、低电或雨滴回充中下发的指令，由设备按协议回拒绝码。
- **倒计时什么时候开始不变**：仍是自动 / 定点选好时长、工作时间（DP119）下发成功后才开始计时；再次设置按新时长重跑，「继续」不重计。
  - 当天曾改为「时间设置弹窗确认即开始计时」（faf57fd），因方案未定已撤回（40fd2e8），代码与改之前一致；原因分析见 `2026-10-24-割草机启动无倒计时原因与改动说明.md`。
  - 设备上报 DP119（面板、定时计划或别的手机设置的工作时间）不会让本机显示倒计时，也不会改动已在走的倒计时；如需支持，要设备侧另给剩余时间或结束时间，暂不改。

## 风险

- 未编译、未跑测试、未真机；已同步改写对应测试用例。
- 黄条依赖设备脱困期间持续报工作状态 12；若固件实际不报 12，脱困提示将不再出现（不再有事件码兜底）。
- 设备还没报工作状态时默认按待机，倒计时也随之隐藏（胶囊同时显示「待机」，两者一致）。
- 倒计时只隐藏不清零：取消任务回到待机后，若机器经面板或定时计划再次作业，旧的倒计时会重新显示；APP 再次设置工作时间则按新时长重跑。如需「回待机即清倒计时」，需产品再定。

## 真机验收

1. 割草中让机器进入坑洼：首页状态「陷坑脱困中」，黄条「机器陷入坑洼，正在脱困」。
2. 脱困中退出首页再进：两处仍显示。
3. 脱困成功：两处恢复为割草中，黄条收起。
4. 脱困失败（困死）：状态「故障」，黄条「机器被困，请移至平坦区域。」
5. 脱困中按急停：状态「急停」，黄条收起。
6. 低电触发回充：状态「低电回充中」；雨检触发回充：状态「雨滴回充中」；手动回桩仍为「回桩中」。
7. 设置工作时间开始割草，倒计时显示后：
   - 机器回到待机：倒计时消失；
   - 机器进入休眠（状态显示「关机」）或长按关机（状态显示「已关机」）：倒计时消失；
   - 断电 / 断网让设备离线：倒计时消失；
   - 停止、回充、在桩等待、陷坑脱困中：倒计时照常显示；
   - 从上面隐藏的状态回到割草：倒计时接着按原来的结束时间显示。
