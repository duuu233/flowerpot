# 割草机 DP5 新增状态与脱困提示改动说明（2026-10-24）

> 依据：协议 V3.0（2026-10-24 更新版）；DP5 状态名称、DP18 黄条文案按产品 2026-10-24 给的平台名称；DP3 工作模式按产品 2026-10-24 给的枚举与拒绝条件。
> 相关提交：fc3e0dd（DP5 新增三种状态）、12191c3（首页黄条脱困提示改跟 DP5）、445a11e（倒计时在待机 / 休眠 / 关机（离线）时隐藏）、b4f1d51（DP5 状态名称与 DP18 黄条文案改为平台名称）、本次提交（DP3 工作模式改为 5 值）。
> 状态：已推送；**未编译、未运行测试、未真机验证**。

## 一句话

设备新报的「脱困中 / 低电回充 / 雨滴回充」首页都能显示了；首页状态和 DP18 黄条文字统一改用平台名称；黄条「机器陷入坑洼，正在脱困」改成跟着工作状态走，不会再漏提示或提前消失；工作时间倒计时在机器待机、休眠、关机（离线）时隐藏；工作模式 DP3 按新枚举（2 = 随机割草、3 = 定点、4 = 回充，1 弃用）对齐。倒计时什么时候开始计时不变。

## 改了什么

### 1. 工作状态新增三种（fc3e0dd）

| 设备报 | 首页状态显示 | 之前 |
| --- | --- | --- |
| 12 escaping | 脱困中 | 认不出，停在上一个状态 |
| 13 goto_charge_low_pwr | 低电回充 | 同上 |
| 14 goto_charge_rain | 雨滴回充 | 同上 |

- 正常回桩仍是 4，显示「回桩」；到桩后仍按原因报 9 / 10，显示「等待充电 / 等待雨停」。
- 以前定稿的「回桩途中要分雨滴还是正常」，设备现在直接报 13 / 14，这一项随之落实。
- 回充事件码（51~53）不用于显示：协议写明回充原因以工作状态为准。
- 首页显示名称见第 4 节（本次已按平台名称统一）。

### 2. 黄条「正在脱困」改跟工作状态（12191c3）

| | 之前 | 现在 |
| --- | --- | --- |
| 什么时候显示 | 收到脱困开始事件（只发一次） | 工作状态是 12「脱困中」（设备每秒重报） |
| 什么时候收起 | 收到脱困结束事件，或 2 分钟到时 | 工作状态变成别的（脱困成功回割草、困死变故障、按急停变急停） |
| 事件那一帧丢了 | 不提示 / 一直挂到 2 分钟 | 不受影响 |
| 脱困途中才打开首页 | 不提示 | 直接显示 |
| 脱困超过 2 分钟（设备最长 180 秒） | 提前消失 | 一直显示到结束 |

- 黄条和首页状态现在说的是同一件事：状态写「脱困中」时，黄条同时提示「机器陷入坑洼，正在脱困」（按产品确认两处都保留；这句来自工作状态，不是 DP18，文字未改）。
- 显示优先级不变：已关机 > 设备故障（DP18）> 设备已抬起 / 已落地 > 正在脱困。脱困失败后显示 DP18 的「机器陷坑」。
- 抬起 / 落地提醒不受影响。

### 3. 倒计时在待机、休眠、关机（离线）时隐藏（445a11e）

按产品口径，下面任一情况成立，首页状态胶囊后面就不显示倒计时：

| 产品说法 | APP 判断依据 | 胶囊显示 |
| --- | --- | --- |
| 待机 | 工作状态 DP5 = 0 standby | 待机 |
| 休眠 | 工作状态 DP5 = 2 sleep | 休眠 |
| 关机 | DP113 上报已关机，且之后没有再开机 | 已关机 |
| 离线 | 设备在线状态为离线 | — |

- 「休眠」「关机（离线）」与设备的几个信号不是一一对应，所以 DP5 = 0、DP5 = 2、DP113 已关机、离线四种都隐藏。
- 只是不显示，倒计时终点保留、照常走；离开这些状态后按原终点接着显示，这时可能已经少了一截或为「0分」。
- 其余状态照旧显示：随机割草、定点割草、绕边割草、暂停、急停、故障、回桩、低电回充、雨滴回充、等待充电、等待雨停、去第二区域、脱困中。

### 5. 工作模式 DP3 按新枚举对齐（本次）

**枚举序 = 传输值**：

| 值 | 标识符 | 含义 | 之前（协议 V3.0） | APP 现在 |
| --- | --- | --- | --- | --- |
| 0 | standby | 待机，取消任务回主页 | 0 standby | 0，可下发 |
| 1 | random | 弃用 | 1 是 smart | 1，认得但**不下发** |
| 2 | smart | 随机割草（首页「自动」） | 2 是 spot | 2，可下发 |
| 3 | spot | 定点割草（首页「定点」） | 3 是 goto_charge | 3，可下发 |
| 4 | goto_charge | 回充 / 回桩（首页「回归」） | 4 是 edge_mowing（占位） | 4，可下发 |

- APP 下发 DP3 一直用标识符（`smart` / `spot` / `goto_charge`），这一点不受序号影响；**但设备拒绝回执（DP115）里的 `val` 和部分上报是序号**，APP 靠它判断「这条拒绝是不是刚才那次操作的」。之前 APP 按 smart = 1、goto_charge = 3 去匹配，设备按新序号回 2 / 4 时对不上，拒绝原因就不会弹出来。现已按新序号改过来。
- 原协议 V3.0 里 DP3 的 4~7（绕边割草 / 去第二区域 / 等待充电 / 等待雨停）已不属于 DP3。「在桩等待充电 / 雨停时停止、继续置灰」改为只看工作状态 DP5 = 9 / 10，效果不变。

**拒绝条件核对**（拒绝由设备判断并回拒绝码，APP 按拒绝理由与文案 V1.0 显示原因）：

| 下发 | 产品给的拒绝条件 | 设备拒绝码 → APP 显示 | APP 下发前自己拦的 |
| --- | --- | --- | --- |
| smart 随机割草 | 休眠、急停、报警、OTA 中、开盖 | 16 机器已关机；19 机器处于急停状态 / 23 请松开急停按钮；26 读故障明细出具体故障；18 固件升级中，暂不接受操作；21 请合上盖子 | 盖子未合（弹「盖子未合上」不下发）；暂停中、已关机、离线时按钮不可点 |
| spot 定点割草 | 同随机割草，另加：在充电、在边界线外 | 同上，另加 32 机器已在充电桩上 / 54 电量小于 70% 已进入充电等待；33 机器在界外，请移回界内 | 同上 |
| goto_charge 回充 | 同随机割草 | 同随机割草 | 同上 |
| standby 待机 | — | 取消任务回待机 | APP 目前没有下发 standby 的按钮 |

- 结论：产品给的每个拒绝条件，拒绝理由 V1.0 里都有对应的码，APP 已能显示对应文案，拒绝逻辑无需改。
- 自动 / 定点开始前仍是：安全确认 → 选割草时间（DP119）→ 再下发 DP3；回归不选时间，只查盖子。

## 没改的

- 停止 / 继续、自动 / 定点 / 回归按钮能不能点的规则不变；脱困中、低电回充或雨滴回充中下发的指令，由设备按协议回拒绝码。
- 本机机器日志里的文字（如「机器在桩等待雨停」「开始沿边割草」）未改；首页三个按钮仍叫「自动 / 定点 / 回归」。
- DP3 拒绝条件的判断在设备侧，APP 的拒绝提示与下发前检查未改。
- **倒计时什么时候开始不变**：仍是自动 / 定点选好时长、工作时间（DP119）下发成功后才开始计时；再次设置按新时长重跑，「继续」不重计。
  - 当天曾改为「时间设置弹窗确认即开始计时」（faf57fd），因方案未定已撤回（40fd2e8），代码与改之前一致；原因分析见 `2026-10-24-割草机启动无倒计时原因与改动说明.md`。
  - 设备上报 DP119（面板、定时计划或别的手机设置的工作时间）不会让本机显示倒计时，也不会改动已在走的倒计时；如需支持，要设备侧另给剩余时间或结束时间，暂不改。

## 风险

- 未编译、未跑测试、未真机；已同步改写对应测试用例。
- 黄条依赖设备脱困期间持续报工作状态 12；若固件实际不报 12，脱困提示将不再出现（不再有事件码兜底）。
- DP18 黄条不再带处理建议（如「请放回地面」），用户只看到故障名称。
- DP3 新序号必须与设备固件一致：若设备仍按协议 V3.0 旧序号（smart = 1、goto_charge = 3）回执，APP 将匹配不上，拒绝原因不弹；协议 V3.0 文档里的 DP3 表仍是旧序号，以本说明为准，建议设备侧同步更新协议文档。
- 设备还没报工作状态时默认按待机，倒计时也随之隐藏（胶囊同时显示「待机」，两者一致）。
- 倒计时只隐藏不清零：取消任务回到待机后，若机器经面板或定时计划再次作业，旧的倒计时会重新显示；APP 再次设置工作时间则按新时长重跑。如需「回待机即清倒计时」，需产品再定。

## 真机验收

1. 割草中让机器进入坑洼：首页状态「脱困中」，黄条「机器陷入坑洼，正在脱困」。
2. 脱困中退出首页再进：两处仍显示。
3. 脱困成功：状态恢复为「随机割草」，黄条收起。
4. 脱困失败（困死）：状态「故障」，黄条「机器陷坑」。
5. 脱困中按急停：状态「急停」，黄条收起。
6. 低电触发回充：状态「低电回充」；雨检触发回充：状态「雨滴回充」；手动回桩为「回桩」；到桩后为「等待充电」或「等待雨停」。
7. 抬起机器超时、翻转机器等触发 DP18：黄条显示对应平台名称（如「机器抬起」「机器翻转」），点开「设备告警」弹窗逐条一致。
8. DP3：点「自动」机器开始随机割草；开盖、急停、休眠、有故障、升级中再点，弹出对应拒绝原因（如「请合上盖子」「机器处于急停状态」）。点「定点」时机器在桩上或在边界线外，弹「机器已在充电桩上」或「机器在界外，请移回界内」。点「回归」机器回桩。
9. 设置工作时间开始割草，倒计时显示后：
   - 机器回到待机：倒计时消失；
   - 机器进入休眠（状态显示「休眠」）或长按关机（状态显示「已关机」）：倒计时消失；
   - 断电 / 断网让设备离线：倒计时消失；
   - 暂停、急停、回桩、等待充电 / 雨停、脱困中：倒计时照常显示；
   - 从上面隐藏的状态回到割草：倒计时接着按原来的结束时间显示。
