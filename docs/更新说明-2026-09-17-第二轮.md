## 1. 定制动画 / 纪念日图片按新要求压缩 —— **已经是这样了，没改代码**

产品这次贴的四条，和同日第一轮（提交 `e817468`）落地的口径**逐条一致**：

| 项 | 要求 | 实现 |
| --- | --- | --- |
| 格式 | JPG Baseline，不能是 Progressive | `package:image` 的 JPEG 编码器只写 `SOF0`，没有渐进模式 |
| 采样 | 4:2:0 | `img.JpegChroma.yuv420`（显式传，默认是 4:4:4） |
| 尺寸 | ≤ 320×240，任意宽高比，小图不放大 | `UploadImage.targetSize`：**等比缩进框**，不裁画面 |
| 文件 | ≤ 500 KB | 质量档 85→35 逐档降，最低一档还超就不传 |

「先按等比例缩放做」也正是现在的做法：320×240 当**设备屏幕的框**，宽高各自不超一边，
竖图压出来是 180×240，设备居中显示两边留白。实现在 `lib/src/shared/media/upload_image.dart`，
定制动画和纪念日两处上传都走它。

## 2 + 3. 定制动画只能单选

- **没选中的格子不再画勾选圈**，只保留选中后那个青色实心圈 + 白勾。以前每张图右上角都顶着一个
  半透明空圈，九宫格看过去像一排待勾的复选框。
- 说明文字「支持多选，选中后可删除；长按可置顶」→「**选中后可删除；长按可置顶**」。
- **代码层面限制成单选**：选中态从 `Set<String>` 改成一个可空的文件 id，「同时选中两张」在类型上
  就不成立，不是靠「点的时候记得把别的清掉」这种约定维持。
  - 点另一张 = 把选中换过去（原来那张的勾消失）；
  - 再点当前这张 = 取消选中，底部切回那条长的「上传图片」按钮。

DP 那边本来也只认单个：157（置顶）一次带一个文件名，155（删除）也是按文件名删一张。

## 4. 日报表一次拿 7 天，左右切日期

水仓水位、土壤湿度、光照、空气湿度、空气温度这五条**日**历史 DP（131 / 134 / 137 / 164 / 165），
设备一次上报 7 天，App 按日期从包里解出那天再画。

- 报表页日视图上方多了一条**日期切换**：`‹ 9月17日（今天） ›`。
- ⚠️ **这一条当时只做了报表页、漏了四个状态页** —— 用户日常点的那条日期切换条其实在
  需水 / 光照 / 空气温度 / 相对湿度四个状态页顶部，它当时既能无限往前翻、曲线也不跟着换。
  同日已修，见 [`history/2026-09/2026-09-17-状态页日期无限往前翻.md`](history/2026-09/2026-09-17-状态页日期无限往前翻.md)。
- **窗口固定 7 天：当天 + 往前 6 天。** 到边箭头就点不动——窗口外设备根本没报，
  做成能一直往前翻只会让人看到空页、以为数据丢了。
- 翻到过去某一天时，曲线右端标的是 **23:45**（今天才是「当前」）。
- 周 / 月视图没有日期可切：它们本来就是「每天一个平均值」的一整段。
- 某一天没数据时的话分三种，不混成一句：
  - 这个指标压根没有历史 DP（电池、PPFD、DLI）；
  - 日包到了但缺这一天（设备那天断电 / 离线）；
  - 这条 DP 从来没到过。
- **状态页和首页那条曲线一点没变**：日包解出来之后，「最新那天」照旧走原来那条路，
  实时推送接点的逻辑一行没改。

### ⚠️ 7 天帧的字节布局是**推断的**，真机上要核一眼

09_12 功能点表里的日帧仍写着单天「3 字节头 + 96 点」，新固件的 7 天布局没有文档。所以 App
**按帧长认**（和 164 / 165 认帧头同一个套路），依次试：

```text
A 每天一块  [年偏移 月 日 (点数) + N点] × D    len == D × (头 + 点数×点宽)
B 一个帧头  [年偏移 月 日] + 96点 × D          len == 3 + 96×D×点宽
C 旧单天    [年偏移 月 日 + 96点]               兜底
```

两种布局的帧长撞不上（点宽 1：99D vs 675；点宽 2：195D vs 1347），认出长度之后还要过日期头校验
（月 1–12、日 1–31、逐日连续，升序降序都认）。

**真机上进报表页看联调日志那一行**，形如：

```text
日 DP131 hex 693字节/7天×96点（每天一块带日期头）09-11→09-17
```

- 认出「旧单天帧」而字节数明显超过一天的量 ⇒ 两种都没认出来，把这行贴回来再定；
- 天数或覆盖日期和实际对不上 ⇒ 排序方向或「起始日」口径要改。

拿到新版功能点表后，把 `TuyaHistoryCodec.decodeDaily` 收成认死的那一种就行，调用方不用动。
