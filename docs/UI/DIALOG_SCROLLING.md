# 弹框长内容与滚动

> 文档类型：UI Implementation Contract
> 状态：Active
> 最后核验：2026-10-14
> 适用范围：花盆与割草机的应用内弹框、底部弹层

内容超出可用高度时，正文必须可纵向滚动，并显示可操作的滚动条；短内容按实际高度收缩，滚动范围为零时不绘制滚动条。确认、取消、保存或关闭按钮放在正文视口之外，不能被长文字挤出屏幕。保留原有强制升级和升级中的关闭限制。

## 当前覆盖

| 类型/入口 | 内容处理 | 操作区 |
| --- | --- | --- |
| `AppDialog`：普通提示、确认、网络提醒、植物引导、DP18/DP115/机器日志提示、启动安全提醒、改名/昵称输入、固件普通及强制提醒 | 标题、正文、自定义内容共用受限滚动区；按钮下面的附加说明独立受限滚动 | 确认/取消固定；`stackActions` 维持原布局 |
| `showAppOptionDialog`：应用语言选择 | 选项列表可滚动并显示滚动条 | 确认/取消固定 |
| 设置选择弹层：温标、时间格式 | 选项区域可滚动，选项文字随内容增高 | 标题行确认/取消固定 |
| App 提醒/强制更新 | 更新说明可滚动 | 立即更新及非强制的稍后再说固定 |
| 检查固件更新 | 版本区域可滚动，长版本号换行 | 稍后/立即更新固定，完整退场规则保留 |
| OTA 进度 | 状态、进度和失败说明可滚动 | 成功/失败关闭按钮固定；升级中仍不可关闭 |
| 时间编辑：花盆时段、割草计划 | 中间内容可滚动；独立的小时/分钟滚轮保留自身控制器 | 取消/保存固定 |
| 休眠延迟 | 说明和滚轮外层内容受限滚动，内外控制器隔离 | 取消/保存固定 |
| 割草计划重叠/恢复默认 | 图标、标题及说明可滚动 | 返回修改或取消/恢复计划固定 |
| 水位校准 | 标题、步骤与指引区域在小屏/大字下可滚动；正常尺寸保留原图布局 | 下一步/完成及取消/关闭固定 |
| Wi-Fi 选择 | 实际网络 `ListView` 配独立滚动条；空态说明也可滚动 | 顶部确认/取消固定 |
| 更多设备信息 DP 诊断 | 可选择的诊断文本可滚动 | 关闭固定 |
| `showAppBottomSheet` 通用外壳 | 普通内容置于可滚动视口；当前没有生产调用方 | 业务内容自行定义操作区 |

`withBlockingProgress` 仅显示固定进度圈，没有长正文，不需滚动条。系统权限、图片选择等原生系统弹层不由这些组件控制。Toast 是临时提示，不属于本轮模态弹框范围。配网失败页原有“一屏平铺、不要滚动条”规则维持。

## 组件约束

- `AppDialogScrollView` 配合 `Flexible`/`Expanded` 使用，父级提供可用高度；普通短内容仍按内容收缩。
- `AppDialogScrollbar` 为每个弹框持有并释放自己的 `ScrollController`，与实际滚动视图明确绑定；`primary: false` 避免共用页面主控制器。
- 滚动条常驻可见且可交互，只处理本层滚动通知；关闭系统自动滚动条以免桌面平台重复显示。Android/iOS 统一使用品牌青色圆角滚动条与浅色轨道，外观不随平台变成默认灰条。
- 时间滚轮和其它内嵌滚动控件使用各自控制器，不把它们的滚动距离作为外层正文距离。
- `showAppBottomSheet` 的内容构建器提供普通、没有垂直 flex 的内容；已经自行滚动的列表应直接使用 `AppDialogScrollbar` 与明确绑定的控制器，避免重复套滚动视口。

## 用户可见的外观

长内容弹框在首次显示就绘制滚动条和轨道，等待或停止手势后不淡出。使用 `RawScrollbar`：品牌深青色滑块、品牌浅色轨道、4px 宽、4px 圆角、至少32px滑块，轨道上下留8px；滚动条只对应正文，短内容零滚动范围时不绘制。

割草计划“编辑周X”的正文视口左右额外留8px，滚动条在右侧独立留白处，内容仍与标题和按钮保持20px对齐。首次显示让用户知道正文下面还有内容；滑到底可看到“复制整周”，取消/保存固定。新增真实弹层回归 `test/features/mower/mower_plan_scrollbar_test.dart` 验证两平台、375×812和320×568的初始绘制、等待不淡出、拖动及按钮位置。
