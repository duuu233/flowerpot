### 两套编码的对齐

DP 154（`memorial_set`）和后端字段不是一套编码，转换都在 `state.dart` /
`app_backend_repository.dart` 里显式做掉：

| | DP 154 | 后端 |
|---|---|---|
| 条目 id | 帧头 4 字节大端 UINT32，设备按它 upsert | `anniversaryId` |
| 内容类型 | 1=文字，2=图片 | `contentType` 0=文字，1=图片 |
| 停用 | 日期字段写 `000000` | 独立接口 `setUserProductAnniversaryVerify` |
| 删除 | 日期字段写 `111111` | 独立接口 `deleteUserProductAnniversary` |
| 文字上限 | 15 个汉字（45 字节） | `content` 1-150 字符 |

- **id 只留一套**：新增时先打后端拿 `anniversaryId`，再拿它去写 DP 帧。后端 id
  全局唯一、落在 32 位无符号范围内，App 不用再维护第二套本地 id，换机之后设备
  上的条目和后端记录仍然对得上。
- 新增接口没有 swagger 模型，返回体里不一定带 id；拿不到就回列表按「标题 +
  日期」找回最新那条（`addAnniversary` 里的兜底），因为没有 id 这条就写不进设备。
- 文字长度以 **DP 的 15 字**为准，编辑页已有这条校验；后端的 150 字更宽，不会先卡住。
- **图片纪念日现在真的能用了**：以前相册挑的图只是本地预览，从来没上传过，帧里
  写的还是上一次的旧 URL。现在保存时先走 `/Client/Basic/setFileUpload` 换成 URL，
  再写帧和后端。

### 换掉的旧实现

`_memorials` 那份 `SharedPreferences` 清单从「唯一真相」降级成缓存。原来的问题是
DP 154 是写入通道、设备不回报，App 是唯一知道有哪些 id 的地方 —— 换手机 / 重装就
全丢，设备上留下没人能命名和删除的孤儿条目。没配后端（纯涂鸦链路、体验模式、
Widget 测试）时仍然走本地那条路径，行为和以前一样。

### `userProductId` 过滤

`getProductAnniversaryList` 原本只有 `pageIndex/pageSize/keyword/startDate/endDate`，
后端确认会补 `userProductId` 并在返回里带上。代码已经按「会有」写，同时留了兜底：
返回里 `userProductId` 缺失（解析成 0）时按「就是这台设备的」处理，多余的行再本地
滤一次，所以后端补之前和补之后都跑得通。

## 四、没能闭环的三项（需要后端或设计先定）

1. **修改密码**。后端 `/Client/User/changePassword` 校验的是**短信验证码**，入参里
   根本没有「原密码」；而 `docs/UI/修改密码.png` 画的是原密码 + 新密码 + 确认密码。
   两边对不上，页面就没接。代码侧已经备好：`FlowerpotState.sendCurrentUserCode()`
   和 `changeLoginPassword({verifyCode, newPassword})`。**页面加一个验证码输入**，
   或者**后端补一个按原密码改的接口**，二选一之后一行就能接上。
2. **海外邮箱账号体系**。功能表写「国外：邮箱验证码注册、密码登录」，但后端只有
   `sendEmail` / `changeUserEmail` / `chkUserEmailNotExist` 这类**绑定/改绑**接口，
   没有邮箱注册和邮箱登录。所以海外仍然走涂鸦自己的邮箱账号体系。要改成后端统一
   管，需要后端补 `userRegisterEmail` / `userLoginEmail`。
3. **微信 / 支付宝快捷登录**。后端有 `setWechatAppLogin`，但 `pubspec.yaml` 里没有
   微信 SDK，原生侧也没有对应的 MethodChannel，接不了。支付宝后端连接口都还没有。
