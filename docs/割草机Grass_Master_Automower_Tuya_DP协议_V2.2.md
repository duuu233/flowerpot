## 1. 通信约定

| DP 类型 | 传输格式 | App 下发 | 设备上报 |
|---|---|---|---|
| bool | 1 字节 0/1 | `false`/`true` | 同左 |
| value | 4 字节大端整数 | 数值(按各 DP 范围) | 数值 |
| enum | 1 字节枚举序 | 枚举字符串(序号=传输值,**不可重排**) | 枚举字符串 |
| string | 字节流 | UTF-8/ASCII 文本或 JSON | 文本/JSON |
| raw | 字节流 | 十六进制字节流 | 十六进制字节流 |
| bitmap | 位图 | —(只上报) | 位图 |

**下发失败的表现**:设备校验不通过时**不回显**,App 控件约 3~5 秒后超时回弹(设备不返回错误码,靠上报值同步真实状态)。

## 3. 控制类 DP

### 3.1 DP3 mode 工作模式(enum 9值, rw)

枚举序=传输值:

| 值 | 枚举 | 说明 |
|---|---|---|
| 0 | standby | 待机 |
| 1 | smart | 随机割草 |
| 2 | spot | 定点割草 |
| 3 | goto_charge | 回桩 |
| 4 | edge_mowing | 沿边割草 |
| 5 | secondary | 第二区域割草 |
| 6 | wait_charge | 等待充电(在桩) |
| 7 | wait_rain | 等待雨停(在桩) |

**App 可下发 4 值**:standby(0) / smart(1) / spot(2) / goto_charge(3)。其余(edge_mowing/secondary/wait_charge/wait_rain)为设备自动状态,**下发被拒**。

| 指令 | 设备行为 | 拒绝条件 |
|---|---|---|
| smart 随机割草 | 走启动自检→按工作时间建计划→出桩割草;低电转等待、雨天转等待 | 关机/非待机/急停/报警/OTA中/盖开 |
| spot 定点 | 同上;**须已在边界内且不在桩** | 同上+在桩/不在边界内 |
| goto_charge 回桩 | 两段式:终止当前计划清场回待机→走自检回桩;已在回桩=幂等;在桩等待=直接进充电;暂停态=先取消暂停再回桩 | 关机/自检中/OTA中/急停/报警/盖开 |
| standby 待机 | 取消所有工作回待机(含回桩中/在桩等待时取消);已待机=幂等 | 关机/自检中/急停/报警 |

**上报口径**(设备 → App):待机=0 / 随机割草=1 / 定点=2 / 回桩=3 / 沿边=4 / 去副区=5 / 在桩等充=6、等雨=7。变化即报(100ms 采样)+查询全量。

### 3.2 DP2 switch_go 工作开关(bool, rw)

| App 操作 | 下发 | 设备行为 | 回显 |
|---|---|---|---|
| 暂停 | `false` | 停刀盘+停行走,保留任务现场,面板显示"已暂停" | `false` |
| 恢复 | `true`(暂停态) | 按暂停点恢复原模式(自检后继续) | `true` |
| 启动 | `true`(待机态) | 按 App 最后下发的 DP3 模式启动 | `true` |

- 只有运行中(DP5=mowing/spot_mowing/goto_charge)可暂停;暂停中重复 false 被拒
- 暂停期间开盖或面板急停键 → 转真急停(需现场解锁),此时 true 被拒
- 暂停态发 DP3=standby = 放弃任务回待机;发 DP3=goto_charge = 放弃任务直接回桩

## 4. 状态上报类 DP(设备 → App,只读)

上报时机:**变化即报**(值变化后 100ms~1s 内推送)+ **周期兜底**(1s~60s 重报防丢包)+ **查询全量**(App 进入面板可触发)。

### 4.1 DP5 status 工作状态(enum 12值)

枚举序=传输值:

| 值 | 枚举 | 值 | 枚举 |
|---|---|---|---|
| 0 | standby 待机 | 5 | paused 暂停 |
| 1 | mowing 割草中 | 6 | fault 故障 |
| 2 | sleep 休眠 | 7 | stop 急停 |
| 3 | spot_mowing 定点 | 8 | edge_mowing 沿边 |
| 4 | goto_charge 回桩 | 9/10 | wait_charge / wait_rain 在桩等待 |
| | | 11 | secondary 第二区域 |

**优先级**:关机(sleep) > 暂停(paused) > 急停(stop) > 故障(fault) > 回桩(goto_charge) > 在桩等待(wait_charge/wait_rain) > 沿边(edge_mowing) > 定点(spot_mowing) > 割草(mowing,含去副区 secondary) > 待机(standby)。

App 判断机器状态以本 DP 为准;在桩等待的具体原因(等充/等雨)也由本 DP 表达(wait_charge=9/wait_rain=10)。注意 DP3 与 DP5 的枚举序**不同**(DP3=9值, DP5=12值),解析时勿混用。

### 4.2 DP13 battery_percentage 剩余电量(value)

0~100(%)。变化≥1% 上报,充电/低电事件即时上报。

### 4.3 DP18 fault 故障告警位图(bitmap 13位)

| bit | 故障 | 触发 |
|---|---|---|
| 0 | left_wheel 左轮异常 | 左轮霍尔/程序异常/**过流/过温** |
| 1 | right_wheel 右轮异常 | 右轮霍尔/程序异常/**过流/过温** |
| 2 | battery 电池异常 | 电池故障 |
| 3 | pose 位姿翻倒 | 机器翻倒 |
| 4 | lift 抬起 | 机器被抬起(持续10s) |
| 5 | boundary 边界信号异常 | 边界线信号丢失 |
| 6 | blade_ocp 刀盘过流 | 刀盘电机过流 |
| 7 | blade_otmp 刀盘过温 | 刀盘电机过温 |
| 8 | blade_stall 刀盘堵转 | 刀盘堵转 |
| 9 | outside 圈外 | 机器在边界外 |
| 10 | spot_out_boundaty 定点出界 | 定点位置不在边界内或在桩上 |
| 11 | trap 陷坑 | 机器陷入坑中 |
| 12 | blade_motor 刀盘电机异常 | 刀盘霍尔/程序异常 |

故障清除有 1 秒恢复确认防抖。明细类通知(碰撞/雨滴/低电/密草/上坡等)不在此位图,走 DP111。

### 4.4 DP111 fault_alarm 故障告警明细(string, JSON)

四层原始位 JSON,键=级别(device=硬件 / error=错误 / function=功能 / circularize=通知),值=该层 32 位位图按位或:

```json
{"device":0,"error":0,"function":0,"circularize":64}
```

**各级 bit 定义**:

| 层 | bit | 含义 |
|---|---|---|
| device | 0/1/2 | 电池 / IMU / FLASH |
| device | 3/4/5 | 左电机 / 右电机 / 刀盘电机 |
| error | 0/1/2 | 位姿翻倒 / 抬起 / 边界信号 |
| error | 3/4/5 | 左过流 / 左过温 / 左霍尔 |
| error | 6/7/8 | 右过流 / 右过温 / 右霍尔 |
| error | 9/10/11 | 刀盘过流 / 刀盘过温 / 刀盘霍尔 |
| error | 12/13/14 | 刀盘堵转 / 不在计划时间 / 圈外 |
| error | 15 | 定点不在边界内 |
| function | 1 | 陷坑 |
| circularize | 0/1/2/3/4/5 | 碰撞 / 雨滴 / 低电 / 陷坑脱困 / 丢信号 / 圈外 |
| circularize | 6/7/8/9 | 刀盘电流0级 / 1级 / 2级 / 密草停顿 |
| circularize | 10/11/12/13 | 刀盘电流4级 / 刀盘过温 / 抬起 / 前上坡 |
| circularize | 14~19 | 边界过渡超时 / 左右传感器故障 / 状态卡死 / 停止确认超时 / 停止确认 |

### 4.5 DP117 charging_status 充电状态(enum 3值)

0=not_charging(未在桩) / 1=charging(在桩充电中,等雨停挂桩也算) / 2=full(已充满在桩挂机)。变化即报+60s 兜底。

### 4.6 DP118 cover_status 盖子开关(bool)

true=合盖,false=开盖。App 启动前预检用。

## 5. 计划与区域类 DP

### 5.1 DP101 mow_schedule 割草计划(raw 88字节, rw)★

**布局**:8 组 × 11 字节。**组 0=全部设置(ALL)**,组 1~7=周一~周日。每组:

| 字节 | 含义 |
|---|---|
| 0-1 | 时段 1 开始(uint16 小端,分钟 0-1440) |
| 2-3 | 时段 1 结束 |
| 4-5 | 时段 2 开始 |
| 6-7 | 时段 2 结束 |
| 8 | 沿边开关(非 0=先绕边) |
| 9 | 时段 1 有效 |
| 10 | 时段 2 有效 |

**两种设置形态(按组 0 是否有效区分)**:

| 载荷形态 | 设备行为 |
|---|---|
| **组 0 有任一有效时段** + 组 1~7 全 00 | **全部设置**:周一~周日每天按组 0 计划执行(等效"每天");组 0 同步写入设备"每天"模板 |
| 组 0 全 00 + 组 1~7 部分有效 | **按天设置**:仅被填的天生效 |
| 全 00 | 清空所有计划 |

组 0 与组 1~7 混发时**以组 0 为准**(组 1~7 被忽略并清空)——App 侧应遵守互斥约定。

**示例 1(全部设置)**:每天 09:00-11:00——只需组 0:

组 0 = `1C 02 94 02 00 00 00 00 00 01 00`(1C 02=540 分=09:00;94 02=660 分=11:00),组 1~7 全 00。

**示例 2(按天)**:仅周一 08:00-10:00——组 0 全 00,组 1 = `E0 01 58 02 00 00 00 00 00 01 00`,组 2~7 全 00。

**设备行为**:长度=88 校验 → 逐组解析(flag≠0 且 start<end≤1440)→ **清空全部旧计划后重建(全量替换,时长≤10 分钟的时段丢弃)** → 落盘 → 重载今日计划+重设下次触发 → RAW 回显。

**触发逻辑**:计划窗到期自动出桩割草;低电转等待、雨天转等待,自动分流。"全部设置"每天到点同样触发(含周六/周日)。

**App 侧注意**:
1. **全量替换**:每次下发覆盖全部计划;全周相同计划只需填组 0
2. 时段时长必须 >10 分钟,否则该时段被丢弃
3. 下发值用 base64(Tuya raw 标准)

### 5.2 DP103 zone_config 区域配置(raw 25字节, rw)

**布局**:5 区 × 5 字节:

| 字节 | 含义 |
|---|---|
| 0 | 区号 1-5(0 时按槽序兜底,>5 整包拒绝) |
| 1 | 割草百分比 0-100(>100 钳 100) |
| 2-3 | 出发点距离(uint16 小端,米;设备侧上限 200) |
| 4 | valid(非 0 有效) |

**示例**(仅区 1:30%、距 5 米、有效):
```
011E0500010200000000030000000004000000000500000000
```

**语义**:
- **全量替换**:每次下发覆盖全部 5 区;未提及(全 0)的区被清除
- **百分比 0 = 删除该区**(即使 valid=1)
- Σ 有效区百分比 >100 → 整包拒绝(设备不应用,原配置保留)
- 区域开关概念已并入本 DP:存在有效区即区域模式,全 0 即随机模式

**设备行为**:校验通过后清空重建 → S5 区落盘 → RAW 回显。消费端按各区百分比分配割草时长、距离决定起点。

### 5.3 DP104 rain_detect_enable + DP105 rain_delay 雨淋设置

- DP104 bool:雨淋检测回充总开关(仅状态变化时才落盘)
- DP105 value:0-120 分钟,雨停后延迟此时长再自动出桩

## 6. 时间类 DP(DP106/107/108/114)

**时区/夏令时语义(重要)**:设备内部时钟为 **UTC**,DP107(时区)/DP108(夏令时)仅用于设备面板与计划时间的本地换算,**变更后无需重发 DP114**。App 显示时间自行按用户本地时区渲染即可。

| DP | 名称 | 格式 | 说明 |
|---|---|---|---|
| 106 | time_sync_enable | bool | 时间自动同步开关:**关闭时 DP114 下发被拒** |
| 107 | timezone | enum 0-24 | UTCA12~UTCB12 共 25 枚举,序号即传输值(20=UTC+8) |
| 108 | dst_enable | bool | 夏令时开关(+1h) |
| 114 | device_time | string | **10 位 UTC 秒级时间戳字符串** |

**DP114 示例**:`1789560000` = 2026-09-16 12:00:00 UTC(北京 20:00)。

**对时流程(App 推荐实现)**:
1. 发 DP106=true
2. 发 DP107=用户时区枚举、DP108=夏令时
3. 发 DP114=当前 UTC 秒字符串
4. 设备面板时钟立即变为本地时间(设备按 UTC+时区+夏令时换算显示)

**注意**:升级固件后设备时钟基准可能偏移,**App 连接后应主动下发一次 DP114 对时**。

## 7. 维护类 DP

### 7.1 DP109 language 机器语言设置(enum 18值, rw)

枚举序=传输值:0 english / 1 german / 2 spanish / 3 french / 4 portuguese / 5 polish / 6 czech / 7 dutch / 8 hungarian / 9 slovenian / 10 italian / 11 danish / 12 finnish / 13 swedish / 14 romanian / 15 slovak / 16 croatian / 17 lithuanian。

**设备行为**:下发越界(>17)拒绝;值变化才落盘(掉电保存);回读回显。对应设备面板"Language"菜单,两边修改互相同步(设备上报)。**注意**:语言切换仅改变设备菜单/显示文案,不中断当前工作。

### 7.2 DP116 ota_status 升级状态(string, ro)

设备主动上报:`"7"`=非待机拒绝升级;`"20"`=升级失败。配合平台固件升级流程使用。

### 7.3 DP119 opearting_time 工作时间(value 1-24h, rw)

每次出桩作业的时长上限。下发限幅+值变化才落盘;面板修改会回报。与面板 Operating time 菜单同源。

> **已下架 DP**(App 勿使用):旧 109 auto_update 自动升级开关(编号已被 language 占用)/ 110 割草高度 / 112 刀片重置 / 113 割草记录 / 115 PIN 验证码——平台与设备均已删除,下发无响应。远程 PIN 解锁/改密功能随之取消(PIN 仅面板本地操作)。

## 8. 拒绝语义汇总(App 失败提示参考)

| 现象 | 可能原因(App 提示建议) |
|---|---|
| mowing/spot 启动被拒 | 机器不在待机、盖子未关、不在边界内(定点)、OTA 中 |
| 回桩下发被拒 | 盖子未关、急停/报警未恢复、OTA 中 |
| 暂停下发被拒 | 机器不在运行状态 |
| 恢复下发被拒 | 急停/报警未恢复、盖子未关 |
| DP114 发了时间没变 | DP106 未开,或升级后时钟基准偏移(App 重发一次即可) |
| 计划设置后不生效 | 设备时钟未对时(先完成对时流程),或时段≤10 分钟被丢弃 |
| DP103 发了没生效 | 区号越界或 Σ百分比>100(整包拒绝,原配置保留) |

## 9. 典型对接时序(App 开发照此串联)

### 9.1 连接后初始化
```
设备上线 → 全量上报(设备自动) → App 用上报值初始化各控件
→ 建议主动下发一次 DP114 对时(消除设备时钟累计偏差)
```

### 9.2 启动割草(待机 → 割草)
```
前置检查:DP118 cover_status=true(盖关)、DP5/DP3=standby(0)
→ 二选一:发 DP3=smart(1) / 发 DP2=true(按上次模式)
→ 等 DP3=smart(1)、DP5=mowing(1) 上报 = 启动成功
```

### 9.3 暂停 / 恢复
```
暂停:DP5=1/3/4(运行中) → 发 DP2=false → 等 DP5=paused(5)
恢复:发 DP2=true → 等 DP5 回作业值
注意:急停(7)/报警(6)态两者都会被拒
```

### 9.4 取消工作(standby)
```
发 DP3=standby → 设备终止计划回待机 → DP3/DP5 上报 standby
适用于:误启动取消、暂停后不继续、回桩途中改变主意(原地停机回待机)、在桩等待时退出等待
```

### 9.5 回桩(goto_charge)
```
待机/作业/暂停态发 DP3=goto_charge → 等 DP5=goto_charge(4) 行驶中
→ 到桩后 DP5=wait_charge(9)、DP117=charging(1)
急停/报警/OTA 中会被拒;已回桩再发=幂等
```

### 9.6 对时(含时区)
```
① DP106=true ② DP107=时区枚举 ③ DP108=夏令时 ④ DP114=当前UTC秒串
→ 设备面板时钟立即正确;改时区/夏令时后无需重发 ④
```

### 9.7 割草计划设置
```
App 本地编辑完整周计划 → 组包 88B(布局见 5.1)→ base64 下发 DP101
→ 设备落盘+重载今日窗 → 到点自动出桩(低电/雨天自动分流)
```
